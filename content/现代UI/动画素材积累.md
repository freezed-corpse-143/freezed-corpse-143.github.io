# 心电图

 ```js
const step = 3;       // 相邻采样点间距：3 CSS 像素
let cursor = 0;       // 当前绘制端点，允许小数
let rate = 120;       // 每秒推进的采样点数
let lastFrame = 0;

function animate(now) {
  if (!playing) return;

  if (lastFrame) {
    cursor = (cursor + (now - lastFrame) * rate / 1000)
      % ((width - 32) / step);
  }
  lastFrame = now;
  draw();
  frameId = requestAnimationFrame(animate);
}
 ```

 每帧推进量是 经过的毫秒数 × 采样率 / 1000。取模使端点到达右边界后回到左侧，开始下一轮扫描。绘制时先清空画布，再以相同坐标重画端点之前的部分；末尾用小数部分插值，让端点平滑移动：

 ```js
function draw() {
  context.clearRect(0, 0, width, height);

  const left = 16;
  const middle = height * .54;
  const scale = height * .30 / amplitude;
  const end = Math.floor(cursor);
  const fraction = cursor - end;

  context.beginPath();
  context.moveTo(left, middle - samples[0] * scale);

  for (let index = 1; index <= end; index++) {
    context.lineTo(
      left + index * step,
      middle - samples[index % samples.length] * scale
    );
  }

  const current = samples[end % samples.length];
  const next = samples[(end + 1) % samples.length];
  const tipX = left + cursor * step;
  const tipY = middle - (current + (next - current) * fraction) * scale;
  context.lineTo(tipX, tipY);

  // 发光波形及细线
  context.shadowColor = '#82f59f';
  context.shadowBlur = 15;
  context.strokeStyle = '#54eb85';
  context.lineWidth = 3;
  context.stroke();
  context.shadowBlur = 0;
  context.strokeStyle = '#c0ffd0';
  context.lineWidth = 1.2;
  context.stroke();

  // 加粗、发光的移动端点
  context.beginPath();
  context.arc(tipX, tipY, 5, 0, Math.PI * 2);
  context.fillStyle = '#d9ffe2';
  context.shadowColor = '#82f59f';
  context.shadowBlur = 17;
  context.fill();
  context.shadowBlur = 0;
}
 ```

 index % samples.length 负责循环读取输入数组；amplitude 由数组最大绝对值计算，用于把不同幅值的数据适配到画布高度。

```dataviewjs
  const nxt = samples[(end + 1) % samples.length];

  const tipY = middle - (cur + (nxt - cur) * fraction) * scale;
  context.lineTo(tipX, tipY);

  context.shadowColor = '#82f59f';
  context.shadowBlur = 15;
  context.strokeStyle = '#54eb85';
  context.lineWidth = 3;

  context.lineWidth = 1.2;
  context.stroke();

  context.beginPath();
  context.arc(tipX, tipY, 5, 0, Math.PI * 2);
  context.fillStyle = '#d9ffe2';
  context.shadowColor = '#82f59f';
  context.shadowBlur = 17;
  context.fill();
  context.shadowBlur = 0;
}

  if (!playing) return;
  if (lastFrame) {
    const span = (width - 32) / step;
    cursor = (cursor + (now - lastFrame) * rate / 1000) % span;
  }
  lastFrame = now;
  draw();
  frameId = requestAnimationFrame(animate);
}
frameId = requestAnimationFrame(animate);
```

# 神经元激活动画

这版代码的**核心动效逻辑**可以概括为：

> **用一条一维的“总传播距离 `distance`”驱动所有动画**，所有视觉元素都只是这个距离的函数。

也就是说，动画不是靠多个独立的 `setTimeout`、多个 CSS class 切换来协调，而是：

1. 把所有传播路径（源神经元树突 → 轴突 → 突触 → 目标神经元接收分支 → 胞体 → 其余分支）拼成一条**虚拟的一维时间轴**；
2. 每一帧只更新 `distance`；
3. 每个 SVG 路径根据 `distance` 决定自己“画到哪”或“亮不亮”。

---

## 一、核心数据结构：把整条通路折算成“长度”

代码里最关键的一段是：

```js
const sourceExtent = Math.max(...cells[0].branches.map(b => b.offset+b.length));
const targetExtent = Math.max(...cells[1].branches.filter(b => !inputIds.has(b.id)).map(b => b.offset+b.length));
const axon = svg.querySelector('.charge-track');
const axonLength = axon.getTotalLength();
let inputLength = 0;
for (const b of chain) { b.incomingOffset = inputLength; inputLength += b.length; }
const synapseLength = Math.hypot(contact.x-terminal.x,contact.y-terminal.y);
const sourceExitLength = Math.hypot(axonStart.x,axonStart.y);
const axonStartDistance = sourceExtent + sourceExitLength;
const axonEnd = axonStartDistance + axonLength;
const inputStart = axonEnd + synapseLength;
const inputEnd = inputStart + inputLength;
const somaEntryLength = Math.hypot(inputRoot.x,inputRoot.y);
const somaArrival = inputEnd + somaEntryLength;
const spreadEnd = somaArrival + targetExtent;
const pauseLength = velocity * .55;
const cycleLength = spreadEnd + pauseLength;
```

这段做了两件事：

### 1. 给每条树突分支算一个 `offset`
```js
b.offset = b.parent < 0 ? 0 : cells[i].branches[b.parent].offset + cells[i].branches[b.parent].length;
```
- 从根部开始，递归累加父分支的长度；
- 每个分支在“虚拟时间轴”上有一个起点 `offset` 和长度 `length`。

### 2. 把整条通路切成若干段
| 距离区间 | 含义 |
|---|---|
| `0 → sourceExtent` | 源神经元胞体 → 树突扩散 |
| `sourceExtent → axonStartDistance` | 胞体 → 轴突起点 |
| `axonStartDistance → axonEnd` | 沿轴突传播 |
| `axonEnd → inputStart` | 突触间隙（化学传递） |
| `inputStart → inputEnd` | 目标神经元接收分支末端 → 根部 |
| `inputEnd → somaArrival` | 根部 → 胞体 |
| `somaArrival → spreadEnd` | 胞体 → 其余分支扩散 |
| `spreadEnd → cycleLength` | 停顿，然后循环 |

这样，**一个 `distance` 就能定位当前信号在整条通路的哪个位置**。

---

## 二、核心渲染：`reveal()` 用 `strokeDasharray` 画路径

```js
const reveal = (path,length,covered) => {
  path.style.strokeDasharray = `${Math.max(0,Math.min(length,covered))} ${length+1}`;
};
```

这是整个动画最核心的视觉技巧：

- 每条路径的 `strokeDasharray` 设为 `已覆盖长度 剩余长度`；
- `covered` 由 `distance - 该路径的起点偏移` 决定；
- 当 `covered <= 0` 时，路径完全不可见；
- 当 `covered >= length` 时，路径完全显示；
- 中间过程就是“光带沿路径生长”。

在 `update()` 里，所有路径都统一用这个函数驱动：

```js
for (const b of cells[0].branches) reveal(b.path,b.length,distance-b.offset);
reveal(axon,axonLength,distance-axonStartDistance);
for (const b of cells[1].branches) {
  const distanceFromRoot = inputIds.has(b.id) ? b.incomingOffset : b.offset;
  const front = inputIds.has(b.id) ? distance-inputStart : distance-somaArrival;
  reveal(b.path,b.length,front-distanceFromRoot);
}
```

这就是“**同一帧内，所有路径按各自偏移同时更新**”的关键。

---

## 三、核心状态机：`update()` 里的 if-else 链

`update()` 里这一大段：

```js
if (distance < sourceExtent) {
  ...
} else if (distance < axonStartDistance) {
  ...
} else if (distance < axonEnd) {
  ...
} else if (distance < inputStart) {
  ...
} else if (distance < inputEnd) {
  ...
} else if (distance < somaArrival) {
  ...
} else {
  ...
}
```

做了两件事：

1. **计算光点位置 `point` **  
   不同区间用不同方式取点：
   - 树突区间：直接固定胞体位置；
   - 轴突区间：`svg.querySelector('.axon').getPointAtLength(...)`；
   - 突触区间：`terminal` 到 `contact` 之间线性插值；
   - 接收分支区间：`b.path.getPointAtLength(...)`；
   - 根部到胞体：线性插值。

1. **计算阶段文字 `label` **  
   每个区间对应一句中文提示，写入 `.phase`。

这部分是**状态机**，但它不是靠多个布尔变量，而是靠 `distance` 落在哪个区间来判断。

---

## 四、核心循环：`tick()`

```js
function tick(time) {
  if (!container.isConnected) return;
  if (previousTime) distance = (distance + Math.min(time-previousTime,100) * velocity / 1000) % cycleLength;
  previousTime = time;
  update();
  requestAnimationFrame(tick);
}
requestAnimationFrame(tick);
```

这是标准的 `requestAnimationFrame` 循环：

- 用 `time - previousTime` 算真实帧间隔，保证速度与帧率无关；
- `Math.min(..., 100)` 防止切后台回来后跳帧过大；
- `% cycleLength` 实现无缝循环；
- `container.isConnected` 在 Dataview 代码块被卸载后停止循环，避免内存泄漏。

---

## 五、一句话总结

这版动画的核心思想是：

> **把整条神经通路映射成一维长度，用一个 `distance` 变量驱动所有路径的 `strokeDasharray` 和光点位置，用一个 `if-else` 链决定当前阶段和文字提示。**

具体来说，最核心的代码就是这三块：

1. **长度折算**：`offset` / `axonStartDistance` / `axonEnd` / `inputStart` / `somaArrival` / `spreadEnd`；
2. **路径揭示**：`reveal()` + `strokeDasharray`；
3. **帧循环**：`tick()` 里 `distance += dt * velocity`，再 `% cycleLength`。

如果你要改动画节奏，只需要动这几个量：

- `velocity`：整体传播速度；
- `pauseLength`：结尾停顿；
- `chain` / `inputIds`：哪些分支算“接收分支”；
- `update()` 里的区间划分：阶段顺序和文字。

function makeNeuron(index) {
  let seed = (index + 1) * 2654435761 >>> 0;
  const random = () => ((seed = (1664525 * seed + 1013904223) >>> 0) / 4294967296);
  const sides = 5 + (index + Math.floor(random() * 3)) % 3;
  let vertices;
  do {
    vertices = Array.from({ length:sides }, (_, k) => {
      const angle = -Math.PI / 2 + k * 2 * Math.PI / sides + (random() - .5) * .07;
      const radius = 40 + (random() - .5) * 11;
      return { x:Math.cos(angle) * radius, y:Math.sin(angle) * radius };
    });
  } while (vertices.some((b, k) => {
    const a = vertices[(k + sides - 1) % sides], c = vertices[(k + 1) % sides];
    return (b.x - a.x) * (c.y - b.y) - (b.y - a.y) * (c.x - b.x) <= 0;
  }));
  const near = (a,b) => ({ x:a.x * .87 + b.x * .13, y:a.y * .87 + b.y * .13 });
  let body = `M ${coord(near(vertices[0],vertices[sides - 1]))}`;
  vertices.forEach((v,k) => {
    const next = vertices[(k + 1) % sides];
    body += ` Q ${coord(v)} ${coord(near(v,next))} L ${coord(near(next,v))}`;
  });
  body += ' Z';
  const axon = vertices.reduce((a,b) => b.x > a.x ? b : a);
  const inputRoot = vertices.reduce((a,b) => b.x < a.x ? b : a);
  const branches = [];
  function fork(from, angle, length, depth, parent, root) {
    const direction = angle + (random() - .5) * .25;
    const to = { x:from.x + Math.cos(direction) * length, y:from.y + Math.sin(direction) * length };
    const bend = (random() - .5) * 8;
    const mid = { x:(from.x + to.x)/2 - Math.sin(direction)*bend, y:(from.y + to.y)/2 + Math.cos(direction)*bend };
    const id = branches.length;
    branches.push({ id, parent, root, depth, from, mid, to, d:`M ${coord(from)} Q ${coord(mid)} ${coord(to)}` });
    if (depth < 3) for (const side of [-1, 1]) {
      if (depth > 0 && random() < .13 + depth * .1) continue;
      fork(to, direction + side * (.31 + random() * .28), length * (.6 + random() * .16), depth + 1, id, root);
    }
  }
  vertices.forEach((v,k) => {
    if (v === axon) return;
    fork({ x:v.x * .94, y:v.y * .94 }, Math.atan2(v.y,v.x), 32 + random()*9, 0, -1, k);
  });
  return { body, axon, branches, inputRoot:vertices.indexOf(inputRoot) };
}

    point = svg.querySelector('.axon').getPointAtLength(distance-axonStartDistance);
    label = '沿长轴突传播';
  } else if (distance < inputStart) {
    const t = (distance-axonEnd)/synapseLength;
    point = {x:terminal.x+(contact.x-terminal.x)*t,y:terminal.y+(contact.y-terminal.y)*t};
    label = '突触传递';
  } else if (distance < inputEnd) {
    const traveled = distance-inputStart;
    const b = chain.find(part => traveled < part.incomingOffset+part.length) || chain[chain.length-1];
    const local = b.path.getPointAtLength(Math.max(0,traveled-b.incomingOffset));
    point = toGlobal(local);
    label = '接收分支末端 → 胞体';
  } else if (distance < somaArrival) {
    const t = (distance-inputEnd)/somaEntryLength;
    point = {x:origin+gap+inputRoot.x*(1-t),y:cy+inputRoot.y*(1-t)};
    label = '接收分支根部 → 胞体';
  } else {
    point = {x:origin+gap,y:cy};
    label = distance < spreadEnd ? '胞体激活 → 其余短分支扩散' : '传播完成 · 即将重播';
  }
  for (const dot of [spark,halo]) {
    dot.setAttribute('cx',point.x);
    dot.setAttribute('cy',point.y);
    dot.setAttribute('visibility','visible');
  }
  phase.textContent = label;
  progress.style.width = `${Math.min(100,100*distance/spreadEnd)}%`;
}

  if (!container.isConnected) return; // Dataview 代码块卸载后停止循环
  if (previousTime) distance = (distance + Math.min(time-previousTime,100) * velocity / 1000) % cycleLength;
  previousTime = time;
  update();
  requestAnimationFrame(tick);
}

# 心脏跳动动画

这段代码的**核心**是 **CSS 动画（`@keyframes`）+ SVG 爱心图形** 的组合。其余部分（背景光晕、圆环、文字）都是烘托氛围的辅助元素。

下面拆解真正的核心部分：

## 1. 心跳动画关键帧（灵魂）

```css
@keyframes heartbeat {
  0%, 7%, 23%, 39%, 100% { transform: scale(1); }
  14% { transform: scale(1.25); }   /* 第一下：强跳 */
  29% { transform: scale(1.13); }   /* 第二下：弱跳 */
}
```

这是整个效果的**核心机制**：
- `14%` 处放大到 **1.25 倍**（第一声“咚”）
- `29%` 处放大到 **1.13 倍**（第二声“嗒”）
- 其余时间回到 **1 倍**（停顿）

一个周期 **1.9 秒**，形成“咚—嗒——咚—嗒——”的真实心跳节奏。

## 2. 爱心的 SVG 路径（造型）

```html
<path fill="url(#red)" 
  d="M160 276 C143 259 44 196 35 129 C25 59 102 37 160 99 
     C218 37 295 59 285 129 C276 196 177 259 160 276Z"/>
```

用 **4 段贝塞尔曲线** 画出爱心轮廓，配合 `linearGradient` 红色渐变填充，是视觉主体。

## 3. 动画绑定（让爱心动起来）

```css
.heart {
  filter: drop-shadow(0 15px 18px #ff235766) drop-shadow(0 0 42px #ff477764);
  animation: heartbeat 1.9s infinite;   /* ← 核心绑定 */
  transform-origin: 50% 50%;            /* 以中心为缩放原点 */
}
```

## 4. 光晕同步呼吸（配合心跳）

```css
@keyframes breathe {
  0%, 7%, 23%, 39%, 100% { opacity: .38; transform: scale(.86); }
  14% { opacity: 1;   transform: scale(1.18); }
  29% { opacity: .72; transform: scale(1.04); }
}
```

光晕用**同样的时间节点**（14%、29%）缩放和变亮，与爱心跳动**完全同步**，增强“心跳”的冲击感。

## 5. 扩散波纹（视觉余韵）

```css
@keyframes ring-one {
  0%, 10% { opacity: 0; transform: scale(.7); }
  15%     { opacity: .75; transform: scale(.95); }
  47%, 100%{ opacity: 0; transform: scale(1.65); }
}
```

圆环在心跳**之后**才扩散淡出，模拟心跳后血液扩散的感觉。

---

## 一句话总结

> **核心 = 一个 SVG 爱心 + 一个 `1.9s` 周期、带两次不同幅度缩放（1.25 / 1.13）的 `@keyframes` 动画。**

```javascript
    });

    // ④ 依次生长（错开延迟，形成从左到右的“生长”感）
    config.segments.forEach((seg, i) => {
        setTimeout(() => {
            if (!isRunning) return;
            segmentEls[i].style.width = seg.value + "%";

            // 文字稍后淡入
            setTimeout(() => {
                if (!isRunning) return;
                segmentEls[i].querySelectorAll(".seg-bar-label, .seg-bar-value").forEach(el => {
                    el.style.opacity = "1";
                });
            }, config.animationDuration * 0.6);
        }, i * config.staggerDelay);
    });

    // ⑤ 计算生长总时长，停留后触发收缩
    const growTotalTime = (config.segments.length - 1) * config.staggerDelay
                        + config.animationDuration;

    loopTimer = setTimeout(() => {
        if (!isRunning) return;
        shrink();
    }, growTotalTime + config.holdDuration);
}

// 收缩动画
function shrink() {
    if (!isRunning) return;

    // 文字先淡出
    segmentEls.forEach(el => {
        el.querySelectorAll(".seg-bar-label, .seg-bar-value").forEach(child => {
            child.style.transition = 'opacity 0.3s ease';
            child.style.opacity = '0';
        });
    });

    // 所有段同时收缩到 0
    segmentEls.forEach(el => {
        el.style.transition = `width ${config.shrinkDuration}ms ease-in`;
        el.style.width = '0%';
    });

    // 收缩完成后停顿，再重新生长
    loopTimer = setTimeout(() => {
        if (!isRunning) return;
        loopTimer = setTimeout(() => {
            if (!isRunning) return;
            grow();
        }, config.loopPause);
    }, config.shrinkDuration);
}

// ============ 启动循环 ============
requestAnimationFrame(() => {
    requestAnimationFrame(() => {
        grow();
    });
});

// ============ 清理 ============
const observer = new MutationObserver(() => {
    if (!document.body.contains(container)) {
        isRunning = false;
        if (loopTimer) clearTimeout(loopTimer);
        observer.disconnect();
    }
});
observer.observe(document.body, { childList: true, subtree: true });
```

## 二、动效核心原理（4 个关键点）

| 关键点 | 代码 | 作用 |
|---|---|---|
| **宽度驱动** | `el.style.width = seg.value + "%"` | 用 CSS 过渡让 `width` 从 0 平滑变到目标值，形成“生长” |
| **错开延迟** | `setTimeout(..., i * config.staggerDelay)` | 每段依次启动，产生从左到右逐段生长的效果 |
| **重排强制生效** | `void barWrapper.offsetWidth` | 让“瞬间归零”立即被浏览器计算，否则下一帧恢复过渡时归零不会显示 |
| **循环调度** | `grow → shrink → grow` 用 `setTimeout` 串联 | 实现无限循环播放 |

## 三、真正“动效”的那一行

如果只挑最核心的一行，就是：

```javascript
segmentEls[i].style.width = seg.value + "%";
```

配合 CSS 里的：

```css
transition: width 2000ms cubic-bezier(...);
```

**宽度变化 + CSS transition = 生长动画**。

其余代码（错开延迟、归零重排、循环调度）都是为了让这个动画**分段、循环、可重复**播放服务的。

## 四、如果想改核心动效

- **改生长曲线**：修改 CSS 里的 `cubic-bezier(...)`，比如换成 `ease-out` 会更“冲出去再停”。
- **改生长顺序**：把 `i * config.staggerDelay` 改成 `(segments.length - 1 - i) * config.staggerDelay` 就变成从右往左。
- **改收缩方式**：目前是同时收缩，如果想让收缩也错开，可以在 `shrink()` 里同样用 `setTimeout` 包一层。
