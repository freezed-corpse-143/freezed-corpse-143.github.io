# 心电图

 ```js
const step = 3;       // 相邻采样点间距：3 CSS 像素
let cursor = 0;       // 当前绘制端点，允许小数
let rate = 120;       // 每秒推进的采样点数
let lastFrame = 0;

function animate(now) {
  if (!playing) return;

  if (lastFrame) {
    cursor = (cursor + (now - lastFrame) * rate / 1000)
      % ((width - 32) / step);
  }
  lastFrame = now;
  draw();
  frameId = requestAnimationFrame(animate);
}
 ```

 每帧推进量是 经过的毫秒数 × 采样率 / 1000。取模使端点到达右边界后回到左侧，开始下一轮扫描。绘制时先清空画布，再以相同坐标重画端点之前的部分；末尾用小数部分插值，让端点平滑移动：

 ```js
function draw() {
  context.clearRect(0, 0, width, height);

  const left = 16;
  const middle = height * .54;
  const scale = height * .30 / amplitude;
  const end = Math.floor(cursor);
  const fraction = cursor - end;

  context.beginPath();
  context.moveTo(left, middle - samples[0] * scale);

  for (let index = 1; index <= end; index++) {
    context.lineTo(
      left + index * step,
      middle - samples[index % samples.length] * scale
    );
  }

  const current = samples[end % samples.length];
  const next = samples[(end + 1) % samples.length];
  const tipX = left + cursor * step;
  const tipY = middle - (current + (next - current) * fraction) * scale;
  context.lineTo(tipX, tipY);

  // 发光波形及细线
  context.shadowColor = '#82f59f';
  context.shadowBlur = 15;
  context.strokeStyle = '#54eb85';
  context.lineWidth = 3;
  context.stroke();
  context.shadowBlur = 0;
  context.strokeStyle = '#c0ffd0';
  context.lineWidth = 1.2;
  context.stroke();

  // 加粗、发光的移动端点
  context.beginPath();
  context.arc(tipX, tipY, 5, 0, Math.PI * 2);
  context.fillStyle = '#d9ffe2';
  context.shadowColor = '#82f59f';
  context.shadowBlur = 17;
  context.fill();
  context.shadowBlur = 0;
}
 ```

 index % samples.length 负责循环读取输入数组；amplitude 由数组最大绝对值计算，用于把不同幅值的数据适配到画布高度。

# 蚂蚁爬线图

 核心是 固定连接线，只移动它上面的虚线背景，不移动整条线或模块：

 ```html
<div class="connector">
  <span class="stream"></span>
</div>
 ```

 ```css
.connector {
  position: relative;
  height: 3px;
  background: #345c49; /* 固定的底线 */
}

.stream {
  position: absolute;
  inset: -1px 0;
  background: repeating-linear-gradient(
    90deg,
    #a1f3bf 0 12px,
    transparent 12px 24px
  );
  background-size: 24px 100%;
  animation: march 700ms linear infinite;
}

@keyframes march {
  to { background-position: 24px 0; }
}
 ```

 每段亮色短划线长 12 px、间隔 12 px；背景每 700 ms 向右移动一个完整周期（24 px），视觉上就会连续“爬动”。

# 柱体生长+流光强调

 核心是两段 CSS 动画：柱体只生长一次；柱体上的 ::after 充当流光，在生长结束后持续循环。不需要 JavaScript。

 ```html
<div class="plot">
  <div class="bar" style="--value: 88%; --delay: .12s"></div>
</div>
 ```

 ```css
.plot {
  border-left: 2px solid #90e5df; /* 左侧坐标轴 */
}

.bar {
  position: relative;
  width: var(--value);
  overflow: hidden;               /* 流光不越出柱体 */
  transform-origin: left center;
  animation: grow 1.15s cubic-bezier(.18, .8, .24, 1) both;
  animation-delay: var(--delay);
}

.bar::after {
  content: "";
  position: absolute;
  inset: 0 auto 0 0;
  width: 55%;
  background: linear-gradient(
    90deg, transparent, #baffdf18 22%,
    #eafff4a0 50%, #baffdf20 78%, transparent
  );
  filter: blur(7px);
  animation: sweep 4.8s linear infinite;
  animation-delay: calc(var(--delay) + 1.15s);
}

@keyframes grow {
  from { transform: scaleX(0); }
  to   { transform: scaleX(1); }
}

@keyframes sweep {
  0%        { transform: translateX(-100%); }
  75%, 100% { transform: translateX(185%); }
}
 ```

 --value 决定柱长；--delay 错开各柱入场。流光每 4.8 秒循环，前 75% 时间向右移动，后 25% 留出间隔。
