# 匹配问题

## 问题定义

给定一个**文本串** `T`（长度为 n）和一个**模式串** `P`（长度为 m），找出 `P` 在 `T` 中所有出现的位置。

```
T = "ABABABCABABABCABABABC"
P = "ABABC"
```

## 朴素算法

### 思路
从 `T` 的每个位置 `i` 开始，逐字符与 `P` 比较，若全部匹配则记录位置，否则从 `i+1` 重新开始。

### 代码
```python
def naive_search(T, P):
    n, m = len(T), len(P)
    res = []
    for i in range(n - m + 1):
        j = 0
        while j < m and T[i + j] == P[j]:
            j += 1
        if j == m:
            res.append(i)
    return res
```

### 复杂度
- 最坏：`O(n × m)`，例如 `T = "AAAAA...A"`，`P = "AAAB"`
- 最好：`O(n)`
- 空间：`O(1)`

### 问题
每次失配后，`i` 只前进一步，`j` 归零，**已经比较过的信息被浪费了**。


## KMP 算法（Knuth-Morris-Pratt）

### 关键概念：next 数组（前缀函数）
`next[j]` 表示 `P[0..j-1]` 的**最长相等前后缀长度**。

以 `P = "ABABC"` 为例：

| j    | 子串   | 最长相等前后缀 | next[j] |
| ---- | ------ | -------------- | ------- |
| 0    | ""     | 0              | -1      |
| 1    | "A"    | 0              | 0       |
| 2    | "AB"   | 0              | 0       |
| 3    | "ABA"  | "A"            | 1       |
| 4    | "ABAB" | "AB"           | 2       |

### 匹配过程
失配时 `j = next[j]`，而不是归零。

```python
def kmp_search(T, P):
    n, m = len(T), len(P)
    # 构建 next 数组
    nxt = [0] * m
    k = 0
    for i in range(1, m):
        while k > 0 and P[i] != P[k]:
            k = nxt[k - 1]
        if P[i] == P[k]:
            k += 1
        nxt[i] = k

    # 匹配
    res = []
    j = 0
    for i in range(n):
        while j > 0 and T[i] != P[j]:
            j = nxt[j - 1]
        if T[i] == P[j]:
            j += 1
        if j == m:
            res.append(i - m + 1)
            j = nxt[j - 1]
    return res
```

### 复杂度
- 时间：`O(n + m)`
- 空间：`O(m)`

### 直观理解
```
位置:  0 1 2 3 4 5 6 7
T:     A B A B A B A C
P:     A B A B A C
                   ↑ j=5 处失配
       0 1 2 3 4 5
```

于是 `j` 从 5 跳到 3，`i` 不回退

```
T:  A B A B A B A C
        A B A B A C
        ↑
        P[0] 对齐到 T[2]
```

## 核心思想

模式串在比较位置 `i` 的子串 `p[0..i]` ，

寻找一个尽可能大的相同的前缀和后缀匹配。

以 `P[0..3] = "ABAB"` 为例，它的最长相等真前后缀是 `"AB"`（长度 `k = 2）：

```
  0   1   2   3  
┌───┬───┬───┬───┐
│ A │ B │ A │ B │
└───┴───┴───┴───┘
前缀 k=2：
┌───┬───┐
│ A │ B │-> 扩展
└───┴───┘
后缀 k=2：
        ┌───┬───┐
        │ A │ B │-> 扩展
        └───┴───┘
```

### 如何递归计算

以 `P[0..3] = "ABABA"` 为例

```
  0   1   2   3   4
┌───┬───┬───┬───┬───┐

		│ A │
		└───┘

        		┌───┐
				│ A │
				└───┘
因为 p[2] == p[4]
所以 next[4] = next[3]+1
```

# Z 算法（扩展 KMP）

## 设定

```
原串（文本）T = "ABAB"      长度 n = 4
T: ┌───┬───┬───┬───┐
   │ A │ B │ A │ B │
   └───┴───┴───┴───┘
     0   1   2   3
模式串       P = "AB"       长度 m = 2
P: ┌───┬───┐
   │ A │ B │
   └───┴───┘
```

## 构造新串

```
S = P + "#" + T
  = "AB" + "#" + "ABAB"
  = "AB#ABAB"
```

```
S: ┌───┬───┬───┬───┬───┬───┬───┐
   │ A │ B │ # │ A │ B │ A │ B │
   └───┴───┴───┴───┴───┴───┴───┘
     0   1   2   3   4   5   6
```

- 位置 0~1：模式串 P
- 位置 2：分隔符 `#`（防止匹配跨越 P 和 T 的边界）
- 位置 3~6：原文本 T

**为什么要加 `#`？**
因为如果不加，`Z[i]` 可能跨越 P 和 T 的边界，得到一个"虚假的匹配"。`#` 和任何字符都不等，一旦比到 `#` 就会停下。

参考 next 数组算法

```
  0   1   2   3   4   5   6
┌───┬───┬───┬───┬───┬───┬───┐
│ A │ B │ # │ A │ B │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
┌───┬───┐
│ A │ B │
└───┴───┘
			┌───┬───┐
			│ A │ B │
			└───┴───┘
					┌───┬───┐
					│ A │ B │
					└───┴───┘
```

## Z-box 的加速

```
  0   1   2   3   4   5   6
┌───┬───┬───┬───┬───┬───┬───┐
│ A │ B │ # │ A │ B │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  0   1   2   3   4   5   6
		    ┌───────┐
		    │ box   │      ← [l=3, r=5)
		    └───────┘
                 
   这段 S[3..4] == S[0..1]
```

**关键**：box 内的**每一个位置**，都可以直接借用"镜像位置"的答案，不需要从头比。
