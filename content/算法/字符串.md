# 匹配问题

## 问题定义

给定一个**文本串** `T`（长度为 n）和一个**模式串** `P`（长度为 m），找出 `P` 在 `T` 中所有出现的位置。

```
T = "ABABABCABABABCABABABC"
P = "ABABC"
```

## 朴素算法

### 思路
从 `T` 的每个位置 `i` 开始，逐字符与 `P` 比较，若全部匹配则记录位置，否则从 `i+1` 重新开始。

### 代码
```python
def naive_search(T, P):
    n, m = len(T), len(P)
    res = []
    for i in range(n - m + 1):
        j = 0
        while j < m and T[i + j] == P[j]:
            j += 1
        if j == m:
            res.append(i)
    return res
```

### 复杂度
- 最坏：`O(n × m)`，例如 `T = "AAAAA...A"`，`P = "AAAB"`
- 最好：`O(n)`
- 空间：`O(1)`

### 问题
每次失配后，`i` 只前进一步，`j` 归零，**已经比较过的信息被浪费了**。


## 三、KMP 算法（Knuth-Morris-Pratt）

### 核心思想
利用模式串自身的**前缀/后缀重复性**，失配时不让 `i` 回退，只移动 `j`。

### 关键概念：next 数组（前缀函数）
`next[j]` 表示 `P[0..j-1]` 的**最长相等前后缀长度**。

以 `P = "ABABC"` 为例：

| j    | 子串   | 最长相等前后缀 | next[j] |
| ---- | ------ | -------------- | ------- |
| 0    | ""     | 0              | -1      |
| 1    | "A"    | 0              | 0       |
| 2    | "AB"   | 0              | 0       |
| 3    | "ABA"  | "A"            | 1       |
| 4    | "ABAB" | "AB"           | 2       |

### 匹配过程
失配时 `j = next[j]`，而不是归零。

```python
def kmp_search(T, P):
    n, m = len(T), len(P)
    # 构建 next 数组
    nxt = [0] * m
    k = 0
    for i in range(1, m):
        while k > 0 and P[i] != P[k]:
            k = nxt[k - 1]
        if P[i] == P[k]:
            k += 1
        nxt[i] = k

    # 匹配
    res = []
    j = 0
    for i in range(n):
        while j > 0 and T[i] != P[j]:
            j = nxt[j - 1]
        if T[i] == P[j]:
            j += 1
        if j == m:
            res.append(i - m + 1)
            j = nxt[j - 1]
    return res
```

### 复杂度
- 时间：`O(n + m)`
- 空间：`O(m)`

### 直观理解
```
T: ...ABABABC...
P:    ABABC
          ↑ 失配
P:      ABABC   ← j 跳到 next[4]=2，继续比较
```
