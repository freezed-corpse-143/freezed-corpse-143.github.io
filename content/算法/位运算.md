# 反码/按位取反/负数

- 反码：符号位不动，数值位取反。
- 补码：反码+1

```
-5 原码: 1000 0101
-5 反码: 1111 1010
-5 补码: 1111 1011   ← 反码 + 1
```

- 按位取反：反转内存所有位

```
 0000 0101   (+5)
~ 
 1111 1010   ← 所有位翻转，得到的是补码表示的 -6
```

- 负数 = 按位取反+1

```
~x = -x - 1
```

现代计算机统一用补码表示。



# +1/-1

减 1：最右边的 1 变为 0，它右边的 0 全部变成 1。

```
x     = 10110000
x - 1 = 10101111
             ↑ 借位一直传到这里
```

加 1：最右边的 0 变成 1，它右边连续的 1 全部变成 0。

```
x     = 10101111
x + 1 = 10110000
```

# x & (x-1)

清除最右边的一个 1，其他位保持不变

```
x         = 10110000
x - 1     = 10101111
-------------------
x & (x-1) = 10100000
```

# x & -x

提取最右边的一个 1，就是常说的 lowbit

```
x       = 10110000
-x      = 01010000
-----------------
x & -x  = 00010000
```

# x & (x+1)

清除末尾连续的 1

```
x         = 10101111
x + 1     = 10110000
-------------------
x & (x+1) = 10100000
```

# x | (x-1)

将末尾连续的 0 置为 1

```
x         = 10110000
x - 1     = 10101111
-------------------
x | (x-1) = 10111111
```

# x | (x+1)

将最右边的一个 0 置为 1

```
x         = 10101111
x + 1     = 10110000
-------------------
x | (x+1) = 10111111
```

# x ^ (x-1)

```
x         = 10110000
x - 1     = 10101111
-------------------
x ^ (x-1) = 00011111
```

从最低位到最右边的 1，全部为 1

# x ^ (x+1)

```
x         = 10101111
x + 1     = 10110000
-------------------
x ^ (x+1) = 00011111
```

从最低位到最右边的 0，全部为 1。

# 异或算法

> `a ^ a  = 0`，`a ^ 0  = a`，异或满足交换律和结合律

## 找出唯一出现奇数次的数

数组里其他数都出现偶数次，只有一个数出现奇数次，求它

```python
def single_number(nums):
    r = 0
    for x in nums:
        r ^= x
    return r

single_number([4,1,2,1,2])  # 4
```

## 找出两个落单的数

```
def two_single(nums):
    r = 0
    for x in nums:
        r ^= x              # r = a ^ b
        
    # 找 a^b 中最低位的 1，用来把数组分成两组
    low = r & (-r)			# 一定有个数的在某位是最低位的1
    
    a = 0
    for x in nums:
        if x & low:
            a ^= x          # 一组里异或，得到 a
    return a, r ^ a         # b = r ^ a

two_single([1,2,1,3,2,5])   # (3, 5)
```

思路：`a^b` 某位为 1，说明 a、b 该位不同，按这一位分组，各自异或就分别得到 a、b。

## 找出缺失的数

`0..n` 中缺了一个数，把下标和值一起异或：

```python
def missing_number(nums):
    r = len(nums)
    for i, x in enumerate(nums):
        r ^= i ^ x
    return r

missing_number([0,1,3])   # 2
```

## 不用临时变量交换两个数

```
a, b = 5, 3
a ^= b
b ^= a
a ^= b
# a=3, b=5
```

（实际工程里不推荐，可读性差，但能说明异或的性质。）
