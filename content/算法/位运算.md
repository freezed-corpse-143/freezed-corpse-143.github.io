
# 定义二进制变量

```
x = 0b1010
print(x)	# 10
```

## 打印二进制变量

```
x = 10
print(bin(x))	# 0b1010
```

# 反码

# +1/-1

减 1：最右边的 1 变为 0，它右边的 0 全部变成 1。

```
x     = 10110000
x - 1 = 10101111
             ↑ 借位一直传到这里
```

加 1：最右边的 0 变成 1，它右边连续的 1 全部变成 0。

```
x     = 10101111
x + 1 = 10110000
```

# x & (x-1)

清除最右边的一个 1，其他位保持不变

```
x         = 10110000
x - 1     = 10101111
-------------------
x & (x-1) = 10100000
```
