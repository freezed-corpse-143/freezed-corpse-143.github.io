# 最大栈/最小栈

普通栈只有 push / pop / top，只能 O(1) 拿到栈顶

最大栈再次在这个基础上多个 getMax()，O(1)，拿到整个栈的最大值。

核心思路：如果要弹出栈中的最大值，需要弹出其前面的所有值，所以，我们只需要维护最大值后面的子序列中的最大值。同理，如果压栈，只需要对比该值与当前最大值，保存一个最大值栈即可。

完整代码

```python
class MaxMinStack2:
	def __init__(self, is_max=True):
		self.is_max = is_max
		self.data = []
		# 保存最值序列
		selft.aux = []
		
	def _better(self, a, b):
		return (a >= b) if self.is_max else (a <= b)
		
	def push(self, val):
		self.data.append(val)
		if not self.aux or self._better(val, self.aux[-1]):
			self.aux.append(val)
			
	def pop(self):
		if not self.data:
			raise IndexError("empty")
		val = self.data.pop()
		if self.aux and val == self.aux[-1]:
			self.aux.pop()
		return val
		
	def get_extreme(self):
		return self.aux[-1] if self.aux else None
```

# 滑动窗口的最大值

核心思想：

出队时，非最大值时，对最大值无影响。所以只需要维护最大值之后的降序最值列。
入队时，如果大于前面的值，前面的值就会受影响。
所以维护一个辅助队列，每次淘汰窗口值时，如果是辅助队列队首值时，就同步更新辅助队列。

每次入队时，比较队尾比较与新值，小于新值，就弹出队尾，直到队尾大于新值，然后将新值插入辅助队列。

```pytho

class Solution:
    def maxInWindows(self, num: List[int], size: int) -> List[int]:
        if not num or size <= 0 or size > len(num):
            return []
        
        res = []
        dq = deque()  # 存下标，对应值单调递减
        
        for i in range(len(num)):
            # 队头超出窗口范围，弹出
            if dq and dq[0] <= i - size:
                dq.popleft()
            
            # 队尾比当前值小，弹出
            while dq and num[dq[-1]] < num[i]:
                dq.pop()
            
            dq.append(i)
            
            # 窗口形成后记录最大值
            if i >= size - 1:
                res.append(num[dq[0]])
        
        return res
```
