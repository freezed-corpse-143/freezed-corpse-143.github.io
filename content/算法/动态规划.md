# 最长公共系列

**示例：** `s1 = "zabc"`，`s2 = "ab"`

- `n = 4`（s 1 长度），`m = 2`（s 2 长度）
- `dp` 表大小：`(n+1) × (m+1) = 5 × 3`

## 第 0 步：初始化 DP 表

所有格子先填 `0`。行 `i` 对应 `s1[0..i-1]`，列 `j` 对应 `s2[0..j-1]`。

```
        j=0    j=1    j=2
       ┌─────┬─────┬─────┐
i=0    │  0  │  0  │  0  │   ← 空串
       ├─────┼─────┼─────┤
i=1    │  0  │     │     │   ← s1[0]='z'
       ├─────┼─────┼─────┤
i=2    │  0  │     │     │   ← s1[0..1]="za"
       ├─────┼─────┼─────┤
i=3    │  0  │     │     │   ← s1[0..2]="zab"
       ├─────┼─────┼─────┤
i=4    │  0  │     │     │   ← s1[0..3]="zabc"
       └─────┴─────┴─────┘
```

列标题：`j=1 → 'a'`，`j=2 → 'b'`

---

## 第 1 步：填 `i=1`（字符 `s1[0]='z'`）

对每个 `j`，比较 `'z'` 与 `s2[j-1]`：

- `j=1`：`'z' ≠ 'a'` → `max(dp[0][1], dp[1][0]) = max(0,0)=0`
- `j=2`：`'z' ≠ 'b'` → `max(dp[0][2], dp[1][1]) = max(0,0)=0`

```
        j=0    j=1    j=2
       ┌─────┬─────┬─────┐
i=0    │  0  │  0  │  0  │
       ├─────┼─────┼─────┤
i=1    │  0  │  0  │  0  │   ← 'z' 与 'a','b' 都不等
       ├─────┼─────┼─────┤
i=2    │  0  │     │     │
       ├─────┼─────┼─────┤
i=3    │  0  │     │     │
       ├─────┼─────┼─────┤
i=4    │  0  │     │     │
       └─────┴─────┴─────┘
```

---

## 第 2 步：填 `i=2`（字符 `s1[1]='a'`）

- `j=1`：`'a' == 'a'` → `dp[1][0] + 1 = 0 + 1 = 1` ✅
- `j=2`：`'a' ≠ 'b'` → `max(dp[1][2], dp[2][1]) = max(0,1)=1`

```
        j=0    j=1    j=2
       ┌─────┬─────┬─────┐
i=0    │  0  │  0  │  0  │
       ├─────┼─────┼─────┤
i=1    │  0  │  0  │  0  │
       ├─────┼─────┼─────┤
i=2    │  0  │  1  │  1  │   ← 'a' 匹配 s2[0]='a'
       ├─────┼─────┼─────┤
i=3    │  0  │     │     │
       ├─────┼─────┼─────┤
i=4    │  0  │     │     │
       └─────┴─────┴─────┘
```

---

## 第 3 步：填 `i=3`（字符 `s1[2]='b'`）

- `j=1`：`'b' ≠ 'a'` → `max(dp[2][1], dp[3][0]) = max(1,0)=1`
- `j=2`：`'b' == 'b'` → `dp[2][1] + 1 = 1 + 1 = 2` ✅

```
        j=0    j=1    j=2
       ┌─────┬─────┬─────┐
i=0    │  0  │  0  │  0  │
       ├─────┼─────┼─────┤
i=1    │  0  │  0  │  0  │
       ├─────┼─────┼─────┤
i=2    │  0  │  1  │  1  │
       ├─────┼─────┼─────┤
i=3    │  0  │  1  │  2  │   ← 'b' 匹配 s2[1]='b'
       ├─────┼─────┼─────┤
i=4    │  0  │     │     │
       └─────┴─────┴─────┘
```

---

## 第 4 步：填 `i=4`（字符 `s1[3]='c'`）

- `j=1`：`'c' ≠ 'a'` → `max(dp[3][1], dp[4][0]) = max(1,0)=1`
- `j=2`：`'c' ≠ 'b'` → `max(dp[3][2], dp[4][1]) = max(2,1)=2`

```
        j=0    j=1    j=2
       ┌─────┬─────┬─────┐
i=0    │  0  │  0  │  0  │
       ├─────┼─────┼─────┤
i=1    │  0  │  0  │  0  │
       ├─────┼─────┼─────┤
i=2    │  0  │  1  │  1  │
       ├─────┼─────┼─────┤
i=3    │  0  │  1  │  2  │
       ├─────┼─────┼─────┤
i=4    │  0  │  1  │  2  │   ← 'c' 不与 'a','b' 相等
       └─────┴─────┴─────┘
```

**DP 表填写完成。** `dp[4][2] = 2`，即 LCS 长度为 2。

---

## 第 5 步：回溯构造 LCS

从 `i=4, j=2` 开始，`res = []`：

### 5.1 `i=4, j=2`
- `s1[3]='c'` vs `s2[1]='b'`：不等
- `dp[3][2]=2 >= dp[4][1]=1` → 向上走 `i=3`

```
        j=0    j=1    j=2
       ┌─────┬─────┬─────┐
i=0    │  0  │  0  │  0  │
       ├─────┼─────┼─────┤
i=1    │  0  │  0  │  0  │
       ├─────┼─────┼─────┤
i=2    │  0  │  1  │  1  │
       ├─────┼─────┼─────┤
i=3    │  0  │  1  │  2  │ ◀ 当前起点
       ├─────┼─────┼─────┤
i=4    │  0  │  1  │  2  │ 
       └─────┴─────┴─────┘
```

### 5.2 `i=3, j=2`
- `s1[2]='b'` == `s2[1]='b'`：匹配 ✅
- `res = ['b']`，`i=2, j=1`

```
        j=0    j=1    j=2
       ┌─────┬─────┬─────┐
i=0    │  0  │  0  │  0  │
       ├─────┼─────┼─────┤
i=1    │  0  │  0  │  0  │
       ├─────┼─────┼─────┤
i=2    │  0  │  1  │  1  │ ◀ 当前（匹配后左上移动）
       ├─────┼─────┼─────┤
i=3    │  0  │  1  │  2  │   匹配 'b'
       ├─────┼─────┼─────┤
i=4    │  0  │  1  │  2  │
       └─────┴─────┴─────┘
```

### 5.3 `i=2, j=1`
- `s1[1]='a'` == `s2[0]='a'`：匹配 ✅
- `res = ['b','a']`，`i=1, j=0`

```
        j=0    j=1    j=2
       ┌─────┬─────┬─────┐
i=0    │  0  │  0  │  0  │
       ├─────┼─────┼─────┤
i=1    │  0  │  0  │  0  │ ◀ 当前
       ├─────┼─────┼─────┤
i=2    │  0  │  1  │  1  │   匹配 'a'
       ├─────┼─────┼─────┤
i=3    │  0  │  1  │  2  │   匹配 'b'
       ├─────┼─────┼─────┤
i=4    │  0  │  1  │  2  │
       └─────┴─────┴─────┘
```

### 5.4 `j=0`，循环结束
`i=1 > 0` 但 `j=0`，不满足 `j > 0`，退出循环。

```
        j=0    j=1    j=2
       ┌─────┬─────┬─────┐
i=0    │  0  │  0  │  0  │
       ├─────┼─────┼─────┤
i=1    │  0  │  0  │  0  │   停在 j=0
       ├─────┼─────┼─────┤
i=2    │  0  │  1  │  1  │   ↑
       ├─────┼─────┼─────┤   │ 回溯路径
i=3    │  0  │  1  │  2  │   │
       ├─────┼─────┼─────┤   │
i=4    │  0  │  1  │  2  │   起点
       └─────┴─────┴─────┘
```

---

## 最终结果

- `res = ['b', 'a']`
- 反转后：`''.join(reversed(['b','a'])) = "ab"`

**LCS("zabc", "ab") = "ab"** ✅

## 回溯路径总结

```
        j=0    j=1    j=2
       ┌─────┬─────┬─────┐
i=0    │  0  │  0  │  0  │
       ├─────┼─────┼─────┤
i=1    │  0  │  0  │  0  │ ◀── 终点(j=0)
       ├─────┼─────┼─────┤
i=2    │  0  │ [1] │  1  │ ◀── 匹配 'a'
       ├─────┼─────┼─────┤
i=3    │  0  │  1  │ [2] │ ◀── 匹配 'b'
       ├─────┼─────┼─────┤
i=4    │  0  │  1  │  2  │ ◀── 起点
       └─────┴─────┴─────┘
```

路径：`(4,2) → (3,2) → (2,1) → (1,0)`，其中 `(3,2)` 和 `(2,1)` 是匹配格。



代码
```python
class Solution:
	def LCS(self, s1: str, s2: str)->str:
		n=len(s1)
		m=len(s2)
		
		dp = [[0]*(m+1) for _ in range(n+1)]
		
		# 填表
		for i in range(1,n+1):
			for j in range(1, m+1):
				if s1[i-1] == s2[j-1]:
					dp[i][j] = dp[i-1][j-1] + 1
				else:
					dp[i][j] = max(dp[i-1][j], dp[i][j-1])
		
		# 回溯构造 LCS
		i, j = n, m
		res = []
		while i > 0 and j> 0:
			if s1[i-1] == s2[j-1]:
				res.append(s1[i-1])
				i -= 1
				j -= 1
			elif dp[i-1][j] >= dp[i][j-1]:
				i -= 1
			else:
				j -= 1
			if not res:
				return '-1'
			else:
				return ''.join(reversed(res))
```

# 最长公共区别：子序列与子串

|              | 最长公共子序列（LCS, Subsequence）           | 最长公共子串（Substring）                                    |
| ------------ | -------------------------------------------- | ------------------------------------------------------------ |
| 是否要求连续 | **不要求连续**                               | **必须连续**                                                 |
| 例子         | `s1 = "abcde"`, `s2 = "ace"` → LCS = `"ace"` | `s1 = "abcde"`, `s2 = "ace"` → 最长公共子串 = `"a"` 或 `"c"` 或 `"e"`（长度为 1） |
| 转移条件     | 相等时从左上角 +1，不相等时取 max            | 相等时从左上角 +1，不相等时直接置 0                          |
| 结果来源     | `dp[n][m]` 一定是最终答案                    | 答案可能出现在 dp 表任意位置，需要边填边记录最大值           |
# 机器人寻路计数问题

```python

from typing import List

class Solution:
    def minPathSum(self, matrix: List[List[int]]) -> int:
        n = len(matrix)
        m = len(matrix[0])

        dp = [[0] * m for _ in range(n)]

        # 起点
        dp[0][0] = matrix[0][0]

        # 第一行
        for j in range(1, m):
            dp[0][j] = dp[0][j - 1] + matrix[0][j]

        # 第一列
        for i in range(1, n):
            dp[i][0] = dp[i - 1][0] + matrix[i][0]

        # 状态转移
        for i in range(1, n):
            for j in range(1, m):
                dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + matrix[i][j]

        return dp[n - 1][m - 1]
```
