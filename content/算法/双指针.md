# 双数组合并

- `A = [1, 2, 3, _, _, _]`，`m = 3`
- `B = [2, 5, 6]`，`n = 3`

目标：把 `B` 合并进 `A`，得到 `A = [1, 2, 2, 3, 5, 6]`。

---

初始：

```
A

┌───┬───┬───┬───┬───┬───┐
│ 1 │ 2 │ 3 │   │   │   │
└───┴───┴───┴───┴───┴───┘
              ▲
             k=5

i=2 指向 A 最后一个有效元素 3
j=2 指向 B 最后一个元素 6

B

┌───┬───┬───┐
│ 2 │ 5 │ 6 │
└───┴───┴───┘
          ▲
         j=2
```

```

  ▲
 j=0
```

比较 `A[i]=3` 与 `B[j]=2`，`A[i]` 更大，把 `3` 放到 `A[k]`：

```
A

┌───┬───┬───┬───┬───┬───┐
│ 1 │ 2 │ 3 │ 3 │ 5 │ 6 │
└───┴───┴───┴───┴───┴───┘
      ▲   ▲
     i=1 k=2

B

┌───┬───┬───┐

└───┴───┴───┘
  ▲
 j=0
```

比较 `A[i]=2` 与 `B[j]=2`，相等时走 `else`，把 `B[j]=2` 放到 `A[k]`：

```
A

┌───┬───┬───┬───┬───┬───┐
│ 1 │ 2 │ 2 │ 3 │ 5 │ 6 │
└───┴───┴───┴───┴───┴───┘
      ▲   ▲
     i=1 k=1

┌───┬───┬───┐

└───┴───┴───┘
```

最终：

```
A

┌───┬───┬───┬───┬───┬───┐
│ 1 │ 2 │ 2 │ 3 │ 5 │ 6 │
└───┴───┴───┴───┴───┴───┘
```

---

用文字概括这个算法的关键点：

1. **从后往前填**：因为 `A` 的末尾是空的，从后往前放不会覆盖还未处理的 `A` 元素。
2. **双指针比较**：`i` 指向 `A` 的有效部分末尾，`j` 指向 `B` 的末尾。
3. **谁大放谁**：每次把较大的元素放到 `A[k]`，然后相应指针左移。
4. **处理剩余**：如果 `B` 还有剩余，直接拷贝到 `A` 前面；如果 `A` 还有剩余，它们已经在正确位置，不用动。

代码：

```python
class Solution:
    def merge(self, A: List[int], m: int, B: List[int], n: int) -> None:
        # 从后往前填充，i 指向 A 的最后一个有效元素，j 指向 B 的最后一个元素，k 指向 A 的末尾
        i, j, k = m - 1, n - 1, m + n - 1
        
        while i >= 0 and j >= 0:
            if A[i] > B[j]:
                A[k] = A[i]
                i -= 1
            else:
                A[k] = B[j]
                j -= 1
            k -= 1
        
        # 如果 B 还有剩余元素，直接拷贝到 A 前面
        # （如果 A 还有剩余，说明它们已经在正确位置，无需处理）
        while j >= 0:
            A[j] = B[j]
            j -= 1
```

# 区间合并

> 桶排序


代码：
```python
def merge(self, intervals):
    if not intervals:
        return []
    intervals = sorted(intervals, key=lambda x: x.start)   # ① 先按 start 升序
    res = [intervals[0]]
    for cur in intervals[1:]:
        last = res[-1]
        if cur.start <= last.end:        # ② 只测重叠，不加 ±1 的容差
            last.end = max(last.end, cur.end)   # ③ 排序后 last.start <= cur.start，start
不用动
        else:
            res.append(cur)
    return res
```

# 最小覆盖字符串

给出两个字符串 s 和 t，要求在 s 中找出最短的包含 t 中所有字符的连续子串。

包含所有字符意味着，假设字符 `c` 在 `t` 中重复两次，子串中 `c` 也要重复两次

取一个经典例子：

- `s = "ADOBECODEBANC"`
- `t = "ABC"`

需要找到 `s` 中最短的、包含 `A`、`B`、`C` 各至少一次的连续子串。

答案应为：`"BANC"`

## 10. 双指针滑动窗口核心说明

```
┌──────────────────────────────────────────────────────┐
│  right 负责扩张窗口，把字符加入 window               │
│                                                      │
│  当 valid == required 时：                           │
│     窗口已经包含 t 中所有字符                        │
│     此时尝试移动 left 收缩窗口                       │
│     在收缩过程中更新最短答案                         │
│                                                      │
│  当窗口不再满足条件时：                              │
│     停止收缩，继续移动 right 扩张                    │
└──────────────────────────────────────────────────────┘
```

用一张简化图表示：

```
s:   A  D  O  B  E  C  O  D  E  B  A  N  C
     └───────────────┘
     第一次满足：ADOBEC

        └────────────────────────┘
        收缩后再次满足：DOBECODEBA

                          └────────┘
                          最终最短：BANC

left  → 只向右移动
right → 只向右移动
```

时间复杂度：

```
O(len(s) + len(t))
```

因为 `left` 和 `right` 都最多遍历 `s` 一次。

空间复杂度：

```
O(len(t))
```

用于存储 `need` 和 `window`。


```python
def minWindow(s: str, t: str) -> str:
    if not s or not t or len(s) < len(t):
        return ""

    from collections import defaultdict

    need = defaultdict(int)
    window = defaultdict(int)

    for ch in t:
        need[ch] += 1

    required = len(need)   # t 中有多少种不同字符
    valid = 0              # 当前窗口中有多少种字符已经满足要求

    left = 0
    start = 0
    min_len = float('inf')

    for right, ch in enumerate(s):
        # 右指针扩张
        if ch in need:
            window[ch] += 1
            if window[ch] == need[ch]:
                valid += 1

        # 当窗口满足条件时，尝试收缩左边界
        while valid == required:
            # 更新最短结果
            if right - left + 1 < min_len:
                min_len = right - left + 1
                start = left

            # 收缩左边界
            left_ch = s[left]
            if left_ch in need:
                if window[left_ch] == need[left_ch]:
                    valid -= 1
                window[left_ch] -= 1
            left += 1

    return "" if min_len == float('inf') else s[start:start + min_len]
```
