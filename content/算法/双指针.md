# 三数之和

- 第一层遍历 v
	- 第二层从 v 向后遍历：变为两数之和为 target - v 的问题

# 双数组合并

代码：

```python
class Solution:
    def merge(self, A: List[int], m: int, B: List[int], n: int) -> None:
        # 从后往前填充，i 指向 A 的最后一个有效元素，j 指向 B 的最后一个元素，k 指向 A 的末尾
        i, j, k = m - 1, n - 1, m + n - 1
        
        while i >= 0 and j >= 0:
            if A[i] > B[j]:
                A[k] = A[i]
                i -= 1
            else:
                A[k] = B[j]
                j -= 1
            k -= 1
        
        # 如果 B 还有剩余元素，直接拷贝到 A 前面
        # （如果 A 还有剩余，说明它们已经在正确位置，无需处理）
        while j >= 0:
            A[j] = B[j]
            j -= 1
```
