# 快速排序的数组实现

> 以数组 `[ 5 | 3 | 8 | 2 | 4]`，为例子

## 初始状态

```
    ┌───┬───┬───┬───┬───┐
    │ 5 │ 3 │ 8 │ 2 │ 4 │
    └───┴───┴───┴───┴───┘
  ↑   ↑               ↑
  i   j             pivot
```

- `pivot`：数组的最右值作为一个比较枢纽
- `i=-1`：表示“小于 pivot 区域”的右边界还没开始
- `j` 从索引 0 开始向右扫描

## j 指向 5

```
arr[j] = 5 > arr[-1] = 4
```

不叫唤

## j 指向 3

```
  ┌───┬───┬───┬───┬───┐
  │ 5 │ 3 │ 8 │ 2 │ 4 │
  └───┴───┴───┴───┴───┘
↑       ↑           ↑
i       j          pivot
```

```
arr[j]= 3 < arr[-1] = 4
```

然后， `i++`，然后交换 `arr[i]` 和 `arr[j]`

```
┌───┬───┬───┬───┬───┐
│ 3 │ 5 │ 8 │ 2 │ 4 │
└───┴───┴───┴───┴───┘
  ↑   ↑           ↑
  i   j          pivot
```

## 继续扫描

重复规则，直到

```
┌───┬───┬───┬───┬───┐
│ 3 │ 2 │ 8 │ 5 │ 4 │
└───┴───┴───┴───┴───┘
      ↑       ↑   ↑
      i       j  pivot
```

## 交换中枢值与第一个区域的结尾

- 继续 `i++`，然后交换，`arr[i]` 和 `pivot`

```
┌───┬───┬───┬───┬───┐
│ 3 │ 2 │ 4 │ 5 │ 8 │
└───┴───┴───┴───┴───┘
          ↑   ↑   ↑
          i   j  pivot
```
