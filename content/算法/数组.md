# 快速排序的数组实现

> 以数组 `[ 5 | 3 | 8 | 2 | 4]`，为例子

## 初始状态

```
    ┌───┬───┬───┬───┬───┐
    │ 5 │ 3 │ 8 │ 2 │ 4 │
    └───┴───┴───┴───┴───┘
  ↑   ↑               ↑
  i   j             pivot
```

- `pivot`：数组的最右值作为一个比较枢纽
- `i=-1`：表示“小于 pivot 区域”的右边界还没开始
- `j` 从索引 0 开始向右扫描

## j 指向 5

```
arr[j] = 5 > arr[-1] = 4
```

不叫唤

## j 指向 3

```
  ┌───┬───┬───┬───┬───┐
  │ 5 │ 3 │ 8 │ 2 │ 4 │
  └───┴───┴───┴───┴───┘
↑       ↑           ↑
i       j          pivot
```

```
arr[j]= 3 < arr[-1] = 4
```

然后， `i++`，然后交换 `arr[i]` 和 `arr[j]`

```
┌───┬───┬───┬───┬───┐
│ 3 │ 5 │ 8 │ 2 │ 4 │
└───┴───┴───┴───┴───┘
  ↑   ↑           ↑
  i   j          pivot
```

## 继续扫描

重复规则，直到

```
┌───┬───┬───┬───┬───┐
│ 3 │ 2 │ 8 │ 5 │ 4 │
└───┴───┴───┴───┴───┘
      ↑       ↑   ↑
      i       j  pivot
```

## 交换中枢值与第一个区域的结尾

- 继续 `i++`，然后交换，`arr[i]` 和 `pivot`

```
┌───┬───┬───┬───┬───┐
│ 3 │ 2 │ 4 │ 5 │ 8 │
└───┴───┴───┴───┴───┘
          ↑   ↑   ↑
          i   j  pivot
```

# 数组合并


## 有序列表合并


```python
def merge(nums1, m, nums2, n):
    i = m - 1          # nums1 有效部分末尾
    j = n - 1          # nums2 末尾
    k = m + n - 1      # 填充位置（nums1 最末尾）

    while i >= 0 and j >= 0:
        if nums1[i] > nums2[j]:
            nums1[k] = nums1[i]
            i -= 1
        else:
            nums1[k] = nums2[j]
            j -= 1
        k -= 1

    # 只剩 nums2 没放完（nums1 剩的本来就在原位，不用动）
    while j >= 0:
        nums1[j] = nums2[j]     # 注意：j 同时也是填充下标
        j -= 1
```

### 示例数据

```
nums1 = [1, 3, 5, 0, 0, 0]   m = 3   (有效部分 [1,3,5])
nums2 = [2, 4, 6]            n = 3
```

初始：
```
i = m-1 = 2   (指向 nums1 有效末尾 5)
j = n-1 = 2   (指向 nums2 末尾 6)
k = m+n-1 = 5 (指向 nums1 最后空位)
```

### 初始状态

```
index:   0   1   2   3   4   5
nums1: ┌───┬───┬───┬───┬───┬───┐
       │ 1 │ 3 │ 5 │ 0 │ 0 │ 0 │
       └───┴───┴───┴───┴───┴───┘
                 ▲           ▲
                 i           k

nums2: ┌───┬───┬───┐
       │ 2 │ 4 │ 6 │
       └───┴───┴───┘
                 ▲
                 j
```
