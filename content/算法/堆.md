
# 最大堆/最小堆

堆是一棵完全二叉树，用数组存储，满足：

- 大顶堆：每个父节点 ≥ 子节点 → 堆顶是最大值
- 小顶堆：每个父节点 ≤ 子节点 → 堆顶是最小值。

数组下标对应关系

```
父节点 i → 左孩子 2i+1, 右孩子 2i+2
子节点 i → 父节点 (i-1) //2
```

完整实现

```python

class Heap:

	def __init__(self, is_max=True):
		self.data = []
		# 大顶堆、小顶堆
		self.is_max = is_max
	
	# 唯一的参数，比较规则
	def _ok(self, parent, child):
		if self.is_max:
			return parent >=child
		else:
			return parent <=child
	
	# 上浮：新元素放到末尾后向上调整	
	def _sift_up(self, i):
		while i > 0:
			parent = (i-1) //2
			if self._ok(self.data[parent], self.data[i]):
				break
			self.data[parent], self.data[i] = self.data[i], self.data[parent]
			i = parent
			
	# 下沉：堆顶被替换后向下调整
	def _sift_down(self, i):
		n = len(self.data)
		while True:
			left, right =  2*i+1, 2i+2
			# 该交换的元素
			target = i
			# 左孩子该去堆顶
			if left < n and not self._ok(self.data[target], self.data[left]):
				target = left
			if right < n and not self._ok(self.data[target], self.data[right]):
				target = right
			if target == i:
				break
			self.data[i], self.data[target] = self.data[target], self.data[i]
			i = target
			
	# 末尾插入元素，上浮
	def push(self,val):
		self.data.append(val)
		self._sift_up(len(self.data)-1)
		
	# 弹出堆顶元素
	def pop(self):
		if not self.data:
			raise IndexError("heap is empty")
		# 取堆顶元素	
		top = self.data[0]
		# 再取末尾元素
		last = self.data.pop()
		if self.data:
			# 移动末尾元素，放到堆顶
			self.data[0] = last
			self._sift_down
		return top
		
	def __len__(self):
		return len(self.data)
	
```


# 保存最小的 K 个数

1. 维护一个大小为 k 的大根堆（堆顶时堆中最大的元素）
2. 遍历数组：
	1. 如果堆的大小小于 k，直接入堆
	2. 如果当前元素小于堆顶元素，则弹出堆顶，将当前元素入堆。
	3. 否则跳过（当前元素比堆中最大的还大，不可能时最小的 k 个之一）
3. 遍历结束后，堆中的所有元素就是最小的 k 个数

```python
import heapq

class Solution:
    def GetLeastNumbers_Solution(self, input: List[int], k: int) -> List[int]:
        if k <= 0 or not input or k > len(input):
            return []
        
        # 大根堆（存负数模拟）
        heap = []
        for num in input:
            if len(heap) < k:
                heapq.heappush(heap, -num)
            elif -num > heap[0]:  # num < 堆顶元素
                heapq.heapreplace(heap, -num)
        
        # 取出并还原为正数
        return [-x for x in heap]
```


# 选择第 K 个元素

> 快速选择思想

1. 选择一个中枢轴，通过比较剩下的元素，分裂成左右两边。
2. 根据左右两边子序列的数目，可以缩小范围，然后更新全局第 K 个元素，在子序列的排序


# 维护数据流的中位数

最优解法是使用两个堆（一个大顶堆+一个小顶堆）来维护数据流，使得：

- 大顶堆（max_heap）：存储较小的一半数据
- 小顶堆（min_heap）：存储较大的一半数据。

并保证：

1. 大顶堆中所有元素<=小顶堆中所有元素
2. 两个堆的大小差不超过 1

```python
import heapq

class Solution:
    def __init__(self):
        self.max_heap = []  # 大顶堆（存负数）
        self.min_heap = []  # 小顶堆

    def Insert(self, num):
        # 1. 插入
        if not self.max_heap or num <= -self.max_heap[0]:
            heapq.heappush(self.max_heap, -num)
        else:
            heapq.heappush(self.min_heap, num)

        # 2. 调整大小，保证 max_heap 大小 >= min_heap 大小，且差值 <= 1
        if len(self.max_heap) > len(self.min_heap) + 1:
            heapq.heappush(self.min_heap, -heapq.heappop(self.max_heap))
        elif len(self.min_heap) > len(self.max_heap):
            heapq.heappush(self.max_heap, -heapq.heappop(self.min_heap))

    def GetMedian(self):
        if len(self.max_heap) == len(self.min_heap):
            return (-self.max_heap
            [0] + self.min_heap[0]) / 2.0
        else:
            return -self.max_heap[0] * 1.0
```
