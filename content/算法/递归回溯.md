# 索引抽象

全排列的本质是索引的排列，元素本身是什么并不影响排列的结构

```python
from typing import List

def permute_indice(n: int): -> List[List[int]]:
	res = []
	used = [False] *
	path = []
	# 核心思想，逐步固定前面的元素进行遍历
	
	def backtrack():
		if len(path) == n:
			res.append(path[:])
			return
		for i in range(n):
			if used[i]:
				continue
			used[i] = True
			path.append(i)
			backtrack()
			path.pop()
			used[i]=False
	backtrak()
	return res
```

# 回溯的通用伪代码

```python
result = []
def backtrack(result, path, choices):
    if 满足结束条件:
        result.append(path.copy())
        return
    for choice in choices:
        if 不合法(choice):  # 剪枝
            continue
        做选择(path, choice)      # 进入下一层
        backtrack(result, path, 新的choices)
        撤销选择(path, choice)    # 回到本层
```

# 岛屿问题

> 维护一个同等大小的的访问矩阵，标记每个位置是否被访问过，每次遇到未被访问过的岛屿格子，说明发现了一个新的岛屿，岛屿数量＋1。然后从这个格子开始进行 BFS 层次遍历，把与它相连的所有陆地都标记为已经访问。

```python

def solve(grid: List[List[str]]) -> int:
	if not grid or not grid[0]:
		return 0
	rows, cols = len(grid), len(grid[0])
	visited = [[False] * cols for _ in range(rows)]
	
	directions = [(-1, 0), (1, 0), (0, -1), (0, -1)]
```
