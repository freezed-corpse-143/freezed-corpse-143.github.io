
# 没有重复项数字的全排列

抽出一个数字，插入剩下全排列的所有位置


# 索引抽象

全排列的本质是索引的排列，元素本身是什么并不影响排列的结构

```python
from typing import List

def permute_indice(n: int): -> List[List[int]]:
	res = []
	used = [False] *
	path = []
	# 核心思想，逐步固定前面的元素进行遍历
	
	def backtrack():
		if len(path) == n:
			res.append(path[:])
			return
		for i in range(n):
			if used[i]:
				continue
			used[i] = True
			path.append(i)
			backtrack()
			path.pop()
			used[i]=False
	backtrak()
	return res
```
