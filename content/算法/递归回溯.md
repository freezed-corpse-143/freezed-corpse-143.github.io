
# 没有重复项数字的全排列

# 索引抽象

全排列的本质是索引的排列，元素本身是什么并不影响排列的结构

```python
from typing import List

def permute_indice(n: int): -> List[List[int]]:
	res = []
	used = [False] *
	path = []
	# 核心思想，逐步固定前面的元素进行遍历
	
	def backtrack():
		if len(path) == n:
			res.append(path[:])
			return
		for i in range(n):
			if used[i]:
				continue
			used[i] = True
			path.append(i)
			backtrack()
			path.pop()
			used[i]=False
	backtrak()
	return res
```

# 回溯的通用伪代码

```python
result = []
def backtrack(path, choices):
    if 满足结束条件:
        result.append(path.copy())
        return
    for choice in choices:
        if 不合法(choice):  # 剪枝
            continue
        做选择(path, choice)      # 进入下一层
        backtrack(path, 新的choices)
        撤销选择(path, choice)    # 回到本层
```
