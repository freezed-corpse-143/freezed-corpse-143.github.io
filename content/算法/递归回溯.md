
# 没有重复项数字的全排列

抽出一个数字，插入剩下全排列的所有位置


# 索引抽象

全排列的本质是索引的排列，元素本身是什么并不影响排列的结构

```python
from typing import List

def permute_indice(n: int): -> List[List[int]]:
	res = []
	used = [False] *
	path = []
	# 核心思想，逐步固定前面的元素进行遍历
	
	def backtrack():
		if len(path) == n:
			res.append(path[:])
			return
		for i in range(n):
			if used[i]:
				continue
			used[i] = True
			path.append(i)
			backtrack()
			path.pop()
			used[i]=False
	backtrak()
	return res
```

# 回溯的通用伪代码

```python
result = []
def backtrack(result, path, choices):
    if 满足结束条件:
        result.append(path.copy())
        return
    for choice in choices:
        if 不合法(choice):  # 剪枝
            continue
        做选择(path, choice)      # 进入下一层
        backtrack(result, path, 新的choices)
        撤销选择(path, choice)    # 回到本层
```

# 岛屿问题

> 维护一个同等大小的的访问矩阵，标记每个位置是否被访问过，每次遇到未被访问过的岛屿格子，说明发现了一个新的岛屿，岛屿数量＋1。然后从这个格子开始进行 BFS 层次遍历，把与它相连的所有陆地都标记为已经访问。

```python

def solve(grid: List[List[str]]) -> int:
	if not grid or not grid[0]:
		return 0
	rows, cols = len(grid), len(grid[0])
	visited = [[False] * cols for _ in range(rows)]
	
	directions = [(-1, 0), (1, 0), (0, -1), (0, -1)]
	for i in range(rows):
		for j in range(cols):
		if grid[i][j] == '1' and not visited [i][j]:
			count += 1
			# BFS 遍历
			queue = deque([(i,j)])
			visited[i][j] = True
			while queue:
				x, y = queue.popleft()
				for dx, dy in directions:
					nx, ny = x+dx, y+dy
					if 0<=nx < rows and 0 <= ny <cols and not visited[nx][ny] and grid[nx][ny] == '1':
					visited[nx][ny] = True
					queue.append((nx, ny))
	return count
```

# N 皇后问题


从 5 × 5 的空棋盘开始，

约定：
- 列号从左到右是 `col 0,1,2,3,4`
- 行号从上到下是 `row 0,1,2,3,4`
- 用 `1 << col` 表示第 `col` 列被占用
- 用整数 `11111₂` 表示 5 列全可用，即 `(1<<5)-1 = 31`

## 第 0 行：还没放皇后

初始状态：

```
列号:   0   1   2   3   4
       ┌───┬───┬───┬───┬───┐
row0   │   │   │   │   │   │
       ├───┼───┼───┼───┼───┤
row1   │   │   │   │   │   │
       ├───┼───┼───┼───┼───┤
row2   │   │   │   │   │   │
       ├───┼───┼───┼───┼───┤
row3   │   │   │   │   │   │
       ├───┼───┼───┼───┼───┤
row4   │   │   │   │   │   │
       └───┴───┴───┴───┴───┘
```

三个占用集合：

```
cols  = 00000   没有任何列被占
diag1 = 00000   主对角线 \ 没有任何冲突
diag2 = 00000   副对角线 / 没有任何冲突
```

当前行可放位置：

```
available = ((1<<5)-1) & ~(cols | diag1 | diag2)
          = 11111 & ~(00000)
          = 11111
```

即这一行 5 个位置都能放：

```
列号:   0   1   2   3   4
       ┌───┬───┬───┬───┬───┐
row0   │ 1 │ 1 │ 1 │ 1 │ 1 │   ← 每一位 1 表示可放
       └───┴───┴───┴───┴───┘
```

我们用 `lowbit` 每次取最右边的 1。为了演示清楚，我们**假设这次选择 col 2**（也就是中间那个位置，对应你图里的 Q）。

不过位运算是从最低位开始取的，所以我们先演示取 `col 0`，再回溯到 `col 2` 的路径。这里直接跳到 **选择 col 2** 的情形：

```
pos = 1 << 2 = 00100
```

放上皇后：

```
       ┌───┬───┬───┬───┬───┐
row0   │   │   │ Q │   │   │
       └───┴───┴───┴───┴───┘
```

## 进入第 1 行前：更新三个占用集合

这是**最关键的一步**，我们一步步算。

### 1. 列占用：直接加上 pos

```
cols = cols | pos = 00000 | 00100 = 00100
```

表示 col 2 被占。

```
列号:   0   1   2   3   4
       ┌───┬───┬───┬───┬───┐
row0   │   │   │ Q │   │   │
       ├───┼───┼───┼───┼───┤
row1   │   │   │ × │   │   │   ← col 2 不能再放
       └───┴───┴───┴───┴───┘
```

### 2. 主对角线 `\`：加 pos 后左移一位

```
diag1 = (diag1 | pos) << 1
      = (00000 | 00100) << 1
      = 00100 << 1
      = 01000
```

`01000` 表示 **col 3** 被主对角线占用：

```
列号:   0   1   2   3   4
       ┌───┬───┬───┬───┬───┐
row0   │   │   │ Q │   │   │
       ├───┼───┼───┼───┼───┤
row1   │   │   │ × │ \ │   │   ← col 3 被 \ 扫到
       └───┴───┴───┴───┴───┘
```

为什么是左移？因为 `\` 往下走一行，列号会 **+1**，所以冲突位置整体左移一位（二进制里左移 = 数值变大 = 列号变大）。

### 3. 副对角线 `/`：加 pos 后右移一位

```
diag2 = (diag2 | pos) >> 1
      = (00000 | 00100) >> 1
      = 00100 >> 1
      = 00010
```

`00010` 表示 **col 1** 被副对角线占用：

```
列号:   0   1   2   3   4
       ┌───┬───┬───┬───┬───┐
row0   │   │   │ Q │   │   │
       ├───┼───┼───┼───┼───┤
row1   │   │ / │ × │ \ │   │ 
       └───┴───┴───┴───┴───┘
```

col 1 被 / 扫到，col 2 被列占，col 3 被 \ 扫到
副对角线 `/` 往下走一行，列号会 **-1**，所以冲突位置整体右移一位。

## 第 1 行：计算可选项

```
cols  = 00100
diag1 = 01000
diag2 = 00010
-----------------------------
cols | diag1 | diag2 = 01110
~(...)              = ...10001
& 11111             = 10001
```

所以：

```
available = 10001
```

对应到棋盘：

```
列号:   0   1   2   3   4

row0   │   │   │ Q │   │   │
       ├───┼───┼───┼───┼───┤
row1   │ 1 │ × │ × │ × │ 1 │   ← 只有 col 0 和 col 4 可选
       └───┴───┴───┴───┴───┘
```

这正好对应你图里 row 1 的 `Q` 在 col 4，而 col 0 是另一个分支。

## 从可选项中“选一个”：lowbit 技巧

```python
pos = available & (-available)
```

`available = 10001`，它的最低位 1 在 col 0：

```
  available  = 10001
 -available  = 01111   （补码）
 &           = 00001
```

所以第一次取到的是 **col 0**。放上皇后：

```
列号:   0   1   2   3   4
       ┌───┬───┬───┬───┬───┐
row0   │   │   │ Q │   │   │
       ├───┼───┼───┼───┼───┤
row1   │ Q │   │   │   │   │
       └───┴───┴───┴───┴───┘
```

然后 `available -= pos`，变成 `10000`，下次循环就会取到 col 4。
