**傅里叶变换是把函数表示为不同频率的复指数的叠加；对离散数据，这个变换可以写成矩阵乘法。**需要区分连续傅里叶变换与离散傅里叶变换（DFT）。

### 1. 连续傅里叶变换

采用角频率 $\omega$ 的一种常见约定：

$$ \boxed{ \hat f(\omega)=\int_{-\infty}^{+\infty}f(t)e^{-i\omega t}\,dt } $$

对应的逆变换为：

$$ f(t)=\frac{1}{2\pi}\int_{-\infty}^{+\infty}\hat f(\omega)e^{i\omega t}\,d\omega. $$

这里 $i^2=-1$，而 $e^{-i\omega t}=\cos(\omega t)-i\sin(\omega t)$。因此，变换是在计算函数与不同频率的正弦、余弦之间的关系。上述积分定义例如适用于绝对可积函数；更一般的情形需要通过极限等方式扩展定义。

### 2. 离散傅里叶变换的矩阵定义

给定 $N$ 个数：

$$ \mathbf x= \begin{bmatrix} x_0&x_1&\cdots&x_{N-1} \end{bmatrix}^{\mathsf T}, $$

离散傅里叶变换定义为：

$$ \boxed{ X_k=\sum_{n=0}^{N-1}x_n e^{-i\frac{2\pi}{N}kn}, \qquad k=0,\ldots,N-1. } $$

令

$$ w_N=e^{-i2\pi/N}, $$

则可以写成：

$$ \boxed{\mathbf X=F_N\mathbf x}, \qquad \boxed{(F_N)_{kn}=w_N^{kn}=e^{-i2\pi kn/N}}. $$

展开矩阵：

$$ \begin{bmatrix} X_0\\ X_1\\ X_2\\ \vdots\\ X_{N-1} \end{bmatrix} = \underbrace{ \begin{bmatrix} 1&1&1&\cdots&1\\ 1&w_N&w_N^2&\cdots&w_N^{N-1}\\ 1&w_N^2&w_N^4&\cdots&w_N^{2(N-1)}\\ \vdots&\vdots&\vdots&\ddots&\vdots\\ 1&w_N^{N-1}&w_N^{2(N-1)}&\cdots&w_N^{(N-1)^2} \end{bmatrix} }_{F_N} \begin{bmatrix} x_0\\ x_1\\ x_2\\ \vdots\\ x_{N-1} \end{bmatrix}. $$

**矩阵的第 $k$ 行对应第 $k$ 个频率，乘以输入向量就得到该频率的复数系数 $X_k$。**

### 3. 逆变换与归一化

傅里叶矩阵满足：

$$ F_N^{*}F_N=NI, $$

其中 $F_N^{*}$ 表示共轭转置。因此：

$$ \boxed{ \mathbf x=F_N^{-1}\mathbf X =\frac1N F_N^{*}\mathbf X. } $$

如果希望矩阵本身是酉矩阵，可以使用对称归一化：

$$ U_N=\frac1{\sqrt N}F_N, \qquad U_N^{*}U_N=I. $$

于是正、逆变换分别为：

$$ \boxed{\mathbf X=U_N\mathbf x,\qquad \mathbf x=U_N^{*}\mathbf X.} $$

### 4. 一个 $N=4$ 的例子

此时 $w_4=-i$，所以：

$$ \boxed{ \begin{bmatrix} X_0\\X_1\\X_2\\X_3 \end{bmatrix} = \begin{bmatrix} 1&1&1&1\\ 1&-i&-1&i\\ 1&-1&1&-1\\ 1&i&-1&-i \end{bmatrix} \begin{bmatrix} x_0\\x_1\\x_2\\x_3 \end{bmatrix}. } $$

例如 $X_0=x_0+x_1+x_2+x_3$，表示直流分量；除以 $4$ 就是输入的平均值。

严格来说，**有限维矩阵定义的是 DFT**。连续傅里叶变换对应积分算子，其中核函数 $e^{-i\omega t}$ 扮演了矩阵元素的角色：

$$ \underbrace{X_k=\sum_n (F_N)_{kn}x_n}_{\text{离散：矩阵乘法}} \quad\longleftrightarrow\quad \underbrace{\hat f(\omega)=\int e^{-i\omega t}f(t)\,dt}_{\text{连续：积分变换}}. $$

# 快速傅里叶变换

**FFT（快速傅里叶变换）是快速计算 DFT 的算法。核心公式来自：把一个 $N$ 点 DFT 拆成两个 $N/2$ 点 DFT，再合并。**

下面推导最常见的基 2 FFT，假设 $N=2^m$。

### 1. 将输入按偶数、奇数下标拆开

记旋转因子：

$$
W_N=e^{-i2\pi/N}.
$$

DFT 定义为：

$$
X_k=\sum_{n=0}^{N-1}x_nW_N^{kn}.
$$

把 $n=2r$ 和 $n=2r+1$ 分开：

$$
X_k=
\sum_{r=0}^{N/2-1}x_{2r}W_N^{2kr}
+
W_N^k\sum_{r=0}^{N/2-1}x_{2r+1}W_N^{2kr}.
$$

由于 $W_N^2=W_{N/2}$，定义：

$$
E_k=\sum_{r=0}^{N/2-1}x_{2r}W_{N/2}^{kr},
\qquad
O_k=\sum_{r=0}^{N/2-1}x_{2r+1}W_{N/2}^{kr}.
$$

其中，$E_k$、$O_k$ 分别是偶数下标子序列、奇数下标子序列的 $N/2$ 点 DFT。

### 2. FFT 的核心合并公式

利用周期性和 $W_N^{N/2}=-1$，得到：

$$
\boxed{
\begin{aligned}
X_k&=E_k+W_N^kO_k,\\
X_{k+N/2}&=E_k-W_N^kO_k,
\end{aligned}
\qquad k=0,\ldots,N/2-1.
}
$$
令 $M=N/2$。前面已经得到：

$$ X_k=E_k+W_N^kO_k. $$

对下标 $k+M$，同样有：

$$ X_{k+M}=E_{k+M}+W_N^{k+M}O_{k+M}. $$

这里需要用到**两个性质**。

**第一，$E_k$ 和 $O_k$ 都具有周期 $M$ **，因为它们是 $M$ 点 DFT：

$$ E_{k+M} =\sum_{r=0}^{M-1}x_{2r}W_M^{(k+M)r} =\sum_{r=0}^{M-1}x_{2r}W_M^{kr} \underbrace{W_M^{Mr}}_{e^{-i2\pi r}=1} =E_k. $$

同理，$O_{k+M}=O_k$。这里将它们的定义按周期延拓到任意整数下标。

**第二，旋转因子变号**：

$$ W_N^{k+M} =W_N^kW_N^{N/2} =W_N^k e^{-i\pi} =-W_N^k. $$

将这两个性质代回：

$$ \begin{aligned} X_{k+N/2} &=E_{k+N/2}+W_N^{k+N/2}O_{k+N/2}\\ &=E_k+(-W_N^k)O_k\\ &=\boxed{E_k-W_N^kO_k}, \qquad 0\le k<N/2. \end{aligned} $$

所以，**频率下标增加 $N/2$ 后，两个子 DFT 的值重复，而奇数下标部分前面的旋转因子变号**，于是加法变成减法。

**每一对输出共享同一个乘积 $W_N^kO_k$，然后分别做加法和减法。**这一步称为“蝶形运算”：

$$
\boxed{
\begin{bmatrix}
X_k\\
X_{k+N/2}
\end{bmatrix}
=
\begin{bmatrix}
1&W_N^k\\
1&-W_N^k
\end{bmatrix}
\begin{bmatrix}
E_k\\
O_k
\end{bmatrix}.
}
$$

继续递归拆分 $E$ 和 $O$，直到长度为 $1$，此时 DFT 就是输入自身。

### 3. 对应的矩阵分解

沿用前面的傅里叶矩阵 $F_N$，令 $M=N/2$，并定义：

$$
D_M=\operatorname{diag}
\left(1,W_N,W_N^2,\ldots,W_N^{M-1}\right).
$$

令 $P_N$ 将输入按偶数下标在前、奇数下标在后重排：

$$
P_N\mathbf x=
\begin{bmatrix}
x_0&x_2&\cdots&x_{N-2}&
x_1&x_3&\cdots&x_{N-1}
\end{bmatrix}^{\mathsf T}.
$$

那么：

$$
\boxed{
F_N=
\underbrace{
\begin{bmatrix}
I_M&D_M\\
I_M&-D_M
\end{bmatrix}
}_{\text{蝶形合并}}
\underbrace{
\begin{bmatrix}
F_M&0\\
0&F_M
\end{bmatrix}
}_{\text{两个较小的 DFT}}
\underbrace{P_N}_{\text{输入重排}}.
}
$$

**FFT 就是不断递归应用这个矩阵分解，把稠密的傅里叶矩阵乘法转化为多层稀疏矩阵乘法。**

### 4. 以 $N=4$ 为例

先计算两个 2 点 DFT：

$$
\begin{aligned}
E_0&=x_0+x_2,&E_1&=x_0-x_2,\\
O_0&=x_1+x_3,&O_1&=x_1-x_3.
\end{aligned}
$$

因为 $W_4=-i$，合并得到：

$$
\boxed{
\begin{aligned}
X_0&=E_0+O_0,\\
X_1&=E_1-iO_1,\\
X_2&=E_0-O_0,\\
X_3&=E_1+iO_1.
\end{aligned}
}
$$

直接计算 DFT 需要 $O(N^2)$ 次运算；FFT 的递推关系为：

$$
T(N)=2T(N/2)+O(N),
$$

因此总复杂度为：

$$
\boxed{T(N)=O(N\log N).}
$$

// ---------- 复数与矩阵 ----------
const z = (re = 0, im = 0) => ({ re, im });
const add = (a, b) => z(a.re + b.re, a.im + b.im);
const mul = (a, b) => z(
  a.re * b.re - a.im * b.im,
  a.re * b.im + a.im * b.re
);
const neg = a => z(-a.re, -a.im);
const nonzero = a => Math.hypot(a.re, a.im) > 1e-9;

const zeros = (n, m = n) =>
  Array.from({ length: n }, () =>
    Array.from({ length: m }, () => z())
  );

function identity(n) {
  const A = zeros(n);
  for (let i = 0; i < n; i++) A[i][i] = z(1);
  return A;
}

function multiply(A, B) {
  const C = zeros(A.length, B[0].length);
  for (let i = 0; i < A.length; i++)
    for (let k = 0; k < B.length; k++)
      for (let j = 0; j < B[0].length; j++)
        C[i][j] = add(C[i][j], mul(A[i][k], B[k][j]));
  return C;
}

function blockDiag(blocks) {
  const size = blocks.reduce((s, A) => s + A.length, 0);
  const R = zeros(size);
  let offset = 0;
  for (const A of blocks) {
    for (let i = 0; i < A.length; i++)
      for (let j = 0; j < A.length; j++)
        R[offset + i][offset + j] = A[i][j];
    offset += A.length;
  }
  return R;
}

function W(n, k) {
  const angle = -2 * Math.PI * k / n;
  return z(Math.cos(angle), Math.sin(angle));
}

function dft(n) {
  return Array.from({ length: n }, (_, k) =>
    Array.from({ length: n }, (_, j) => W(n, k * j))
  );
}

// P_n x = [偶数下标输入, 奇数下标输入]
function permutation(n) {
  const P = zeros(n);
  const order = [
    ...Array.from({ length: n / 2 }, (_, i) => 2 * i),
    ...Array.from({ length: n / 2 }, (_, i) => 2 * i + 1)
  ];
  order.forEach((column, row) => P[row][column] = z(1));
  return P;
}

// B_n = [ I  D ; I -D ]
function butterfly(n) {
  const B = zeros(n);
  const m = n / 2;
  for (let k = 0; k < m; k++) {
    B[k][k] = z(1);
    B[k][k + m] = W(n, k);
    B[k + m][k] = z(1);
    B[k + m][k + m] = neg(W(n, k));
  }
  return B;
}

function fmt(a) {
  const clean = v => Math.abs(v) < 1e-9 ? 0 : v;
  const re = clean(a.re), im = clean(a.im);
  const num = v => Number(v.toFixed(3)).toString();
