# 模组安装

1. 官网 https://github.com/Pathoschild/SMAPI/releases 下载压缩包解压。并运行 `install on Windows.bat`
2. 在 Steam 里：游戏->右键属性->启动选项，粘贴

```
"C:\prgram files (x86)\steam\steamapps\common\Stardew Valley\StardewModdingAPI.exe" %command%
```

# 推荐模组

- Auto fisher
- Auto Perfect Fishing
# 模组下载

1. 进入 https://www.nexusmods.com/ 搜索名字
2. 进入页面后，转到 file 页面下。
