# 模组安装

1. 官网 https://github.com/Pathoschild/SMAPI/releases 下载压缩包解压。并运行 `install on Windows.bat`
2. 在 Steam 里：游戏->右键属性->启动选项，粘贴

```
"C:\prgram files (x86)\steam\steamapps\common\Stardew Valley\StardewModdingAPI.exe" %command%
```

# 传说之鱼

*   **地点**：**深山湖泊**（矿井外的那片湖），浮标要抛到**离岸至少 4-5 格**的深水区，湖中央的木桩附近是经典钓点。
*   **时间**：**春季**的**雨天**，早上 6:00 到晚上 22:00 之间。
*   **等级**：**钓鱼 10 级**（吃料理临时提升也算）。
*   **概率**：满足条件后，每次抛竿有 **10%** 的概率咬钩，用**珍稀诱钩**能提升到 **20%**

*   **只能钓一次**：一个存档里每位玩家**仅能钓到一次**传说之鱼。
*   **魔法鱼饵**：在姜岛齐先生核桃房可以买**魔法鱼饵**，用了之后**无视季节和天气**限制，随时都能在深山湖泊挑战它。

## 矿石及其资源

- [x] **铜矿石 / 铜锭**：铜矿石主要在**矿井 1-39 层**挖铜矿点获得。铜锭需要用**熔炉**，消耗 5 个铜矿石 + 1 个煤炭冶炼。
- [x] **铁矿石 / 铁锭**：铁矿石主要在**矿井 40-79 层**挖铁矿点获得。铁锭用熔炉，消耗 5 个铁矿石 + 1 个煤炭冶炼。
- [x] **黄金矿石 / 金锭**：黄金矿石主要在**矿井 80-120 层**挖金矿点获得。金锭用熔炉，消耗 5 个黄金矿石 + 1 个煤炭冶炼。
- [x] **铱矿石 / 铱锭**：铱矿石主要在**骷髅洞穴**或**火山地牢**挖铱矿点获得。铱锭用熔炉，消耗 5 个铱矿石 + 1 个煤炭冶炼。
- [x] **放射性矿石 / 放射性矿锭**：只能在**危险矿井**或**危险骷髅洞穴**中挖放射性矿点获得，通常需要接取齐先生的任务开启危险模式。放射性矿锭用熔炉，消耗 5 个放射性矿石 + 1 个煤炭冶炼。
- [x] **煤炭**：敲碎矿井里的普通石头有概率掉落，也可以用**木炭窑**消耗 10 个木材烧制。
- [x] **精炼石英**：用熔炉加工**石英**或**火石英**（各 1 个 + 1 煤炭）获得，把**破损的 CD **或**破损的眼镜**放进回收机也有概率得到。

- [x] **木材**：砍树获得，树桩也给少量。
- [x] **硬木**：用**斧头**砍**大树桩**或**大圆木**获得，秘密森林里每天都会刷新几个大树桩。
- [x] **石头**：敲碎普通石头获得。
- [x] **粘土**：用**锄头**在农场或矿井里挖**蚯蚓点**（古物斑点）有概率获得。
- [x] **树液**：砍树时概率掉落。
- [x] **纤维**：用**镰刀**割杂草，或在矿井里割草获得。
