# 微光湖转化

## 功能性永久增益

这类转化能提供永久属性加成或装备升级，是微光最有价值的用途。

*   **生命与魔力**：生命水晶 → 活力水晶（提升生命再生）；魔力水晶 → 奥术水晶（提升魔力再生）；生命果 → 埃癸斯果（永久+4 防御）。
*   **永久属性消耗品**：任意水果（葡萄除外） → 珍馐（永久+5%采矿/建造速度）；金蠕虫 → 黏性蠕虫（永久+3 渔力）；粉珍珠 → 银河珍珠（永久增加运气）。
*   **装备升级**：混沌传送杖 → 和谐杖（取消扣血负面效果，需击败月总）；环境改造枪 → 泰拉改造器（范围速度提升，33%不耗弹药）；星星斗篷 → 炫彩斗篷（免疫微光穿透）；附魔日晷 → 附魔月晷；商贩帽 → 商贩背包（永久增加旅商一个售卖栏位）。


## 装饰与杂项

*   **火把与篝火**：几乎所有火把（蓝、骨、珊瑚、腐化、猩红、恶魔、沙漠、绿、神圣、冰、灵液、蘑菇、橙、紫、彩虹、红、黄、白、超亮） → 以太火把；篝火 → 以太篝火；信号弹 → 微光信号弹。
*   **物块与墙**：各色砖块 → 对应的远古砖块；地牢蓝/绿/粉砖墙 → 诅咒砖墙；夜明砖根据月相变化为不同砖块（天堂熔炉砖、月锈砖等）。
*   **特殊物品**：法老面具 → 沙暴瓶；法老长袍 → 飞毯；天使雕像 → 以太天塔柱；整蛊坐垫 → 气阱；闪耀史莱姆气球 → 天后史莱姆。

## 合成拆解

*   **拆解限制**：部分物品无法拆解或拆解结果固定。例如，用骨头制作的物品需击败骷髅王后才能拆解；用丛林蜥蜴砖制作的物品需击败石巨人后。一些物品（如炖兔兔、暴雪瓶）则完全无法拆解，以防止不正当利用。

# 刷怪场

## 地狱篇

1. 挂机点：边缘放两个物块（成 U 形），敲成半砖，放岩浆，直到岩浆溢出成瀑布，用来防止法师。
2. 刷怪点：在下方 47 格左右，用地牢砖（蓝砖或者绿砖）左搭 84 × 2 的地牢砖，右搭 84 × 2 的地牢转。
3. 在重型工作台，将地牢砖合成板墙和砖墙两种，分别去微光湖转为危险的墙。
4. 刷怪点：歌咏危险的板墙和砖墙铺 84 × 3 的墙
5. 挂机点各用危险的墙覆盖人物背景。
