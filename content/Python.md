# 浅拷贝和深拷贝

在 Python 的上下文中（特别是拷贝机制），**“独立”**和**“完全独立”**通常用来区分**浅拷贝（Shallow Copy）**和**深拷贝（Deep Copy）**。

它们的核心区别在于：**能否彻底切断与原对象内部嵌套子对象的关联**。

为了让你一眼看明白，我们先看结论，再看代码图解：

### 1. 核心区别（结论）

|特性|独立（浅拷贝）|完全独立（深拷贝）|
|---|---|---|
|**操作方式**| `copy.copy()` 或 `a[:]` | `copy.deepcopy()` |
|**最外层容器**|**完全独立**（新建对象）|**完全独立**（新建对象）|
|**内部的子对象**（如嵌套的列表/字典）|**不独立**（**共享**同一个子对象）|**完全独立**（递归创建了全新的子对象）|
|**修改顶层元素**（如 `list[0] = x`）|互不影响 ✅|互不影响 ✅|
|**修改内层元素**（如 `list[0][0] = x`）|**互相影响** ❌|互不影响 ✅|

---

### 2. 案例剖析

看下面的例子，`a` 是一个嵌套列表（列表里面套列表）：

 import copy  
 ​  
 a = [[1, 2], [3, 4]]  
 ​  
 # b 是 独立（浅拷贝）——只拷贝了最外层  
 b = a[:]    
 ​  
 # c 是 完全独立（深拷贝）——递归拷贝了所有层  
 c = copy.deepcopy(a)  
 ​  
 # ---------- 实验：修改内层元素 ----------  
 a[0][0] = 99  
 ​  
 print(b)  # 输出: [[99, 2], [3, 4]]  <-- 被影响了！  
 print(c)  # 输出: [[1, 2], [3, 4]]   <-- 完好无损！

---

### 3. 内存图解

为了搞清楚为什么 `b` 会被影响，我们看看内存里的指向关系：

- **变量 `a` **：指向最外层的盒子。
    
- **变量 `b`（独立）**：`b = a[:]` 新建了一个**外层盒子**，但里面的两个小盒子（内层列表）**直接复制了地址**，和 `a` 共享。
    
- **变量 `c`（完全独立）**：`deepcopy` 连里面的两个小盒子也新建了。
    

 1. 原始对象 a  
 ┌─────────────────────┐  
 │     最外层列表 A      │  
 │  ┌──────┐ ┌──────┐  │  
 │  │内层 1 │ │内层 2 │  │  
 │  └──────┘ └──────┘  │  
 └─────────────────────┘  
 ​  
 2. 执行 b = a[:] 后（b 独立）  
 ┌───────────┐         ┌───────────┐  
 │ 外层列表 A │ ←── a   │ 外层列表 B │ ←── b  
 │ ┌──────┐  │         │ ┌──────┐  │  
 │ │内层 1 │◀─┼─────────┼─│内层 1 │◀─┼── 指向同一个内层对象！  
 │ └──────┘  │         │ └──────┘  │  
 │ ┌──────┐  │         │ ┌──────┐  │  
 │ │内层 2 │◀─┼─────────┼─│内层 2 │  │  
 │ └──────┘  │         │ └──────┘  │  
 └───────────┘         └───────────┘  
 ​  
 3. 执行 c = deepcopy(a) 后（c 完全独立）  
 ┌───────────┐         ┌───────────┐  
 │ 外层列表 A │         │ 外层列表 C │ ←── c  
 │ ┌──────┐  │         │ ┌──────┐  │  
 │ │内层 1 │  │         │ │内层 3 │  │ ← 全新的内层对象！  
 │ └──────┘  │         │ └──────┘  │  
 │ ┌──────┐  │         │ ┌──────┐  │  
 │ │内层 2 │  │         │ │内层 4 │  │  
 │ └──────┘  │         │ └──────┘  │  
 └───────────┘         └───────────┘

### 4. 什么时候必须用“完全独立”？

当你修改的对象**不是整个替换元素**（如 `b[0] = 100`），而是**修改元素内部的属性**（如 `b[0].append(100)` 或 `b[0][0] = 100`）时，就必须使用深拷贝（完全独立），否则原始数据会被污染。

### 5. 一句话总结

- **独立（浅拷贝）** = 你复印了一张纸条，但纸条上写着的**储物柜编号（引用）**和原来那张一模一样。你打开储物柜改东西，两张纸条都能看到变化。
    
- **完全独立（深拷贝）** = 你把储物柜里的东西**全部取出来，复印了一份**，放进了全新的柜子里。不管你怎么改新柜子，都不影响原来的旧柜子。
