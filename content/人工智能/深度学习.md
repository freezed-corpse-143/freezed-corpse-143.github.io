# 因果注意力的位置信息

多层因果 Transformer 的掩码结构本身提供了隐式位置信息；位置编码则把位置或相对距离显式引入计算，使得这些信息更容易被学习和使用。并不是叠了多层，掩码矩阵才具有位置信息。**单层掩码已经包含不同位置的可见范围；多层计算让这种结构差异能够通过中间表示传播、被后续位置利用。** 但由于 softmax 加权平均等操作，这些结构信息不一定都能保留。

|      | 仅靠因果掩码              | 加入位置编码或位置机制            |
| ---- | ------------------- | ---------------------- |
| 学习顺序 | 需要从前缀混合的结果中提取顺序线索   | 可以直接利用位置相关的表示或打分       |
| 学习距离 | 需要间接推断两个 token 相隔多远 | 可直接让注意力依赖位置或相对距离       |
| 优化负担 | 同时学习如何表示位置、如何利用位置   | 预先提供位置结构，让模型更容易学习如何利用它 |
