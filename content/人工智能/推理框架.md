# 统一框架

 ```text
推理框架
├─ 接入面：HTTP / CLI / C API / Python API
├─ 请求面：模板、分词、参数校验、输入预处理
├─ 控制面：调度、批处理、生命周期、分布式协调
├─ 状态面：KV Cache、latent、RNG、前缀树、请求状态
├─ 数据面：模型 forward、计算图、算子、kernel
├─ 资源面：显存、内存、mmap、权重驻留、设备间传输
├─ 平台面：CUDA / ROCm / Metal / Vulkan / CPU 等
└─ 工件面：模型格式、配置、权重解析、量化与转换
 ```

 四个项目的根本区别，不是“支持哪些模型”，而是把哪一层当作自己的核心抽象：

 - vLLM：以吞吐为中心的 LLM 请求调度器 + KV Cache 管理器。
 - SGLang：以共享前缀和复杂生成程序为中心的 状态感知调度器。
 - llama.cpp：以可移植、可嵌入为中心的 张量运行时 + 模型运行库。
 - stable-diffusion.cpp：以多组件生成流程为中心的 扩散管线编排器 + GGML 执行器。
