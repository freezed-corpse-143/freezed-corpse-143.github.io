# 浅拷贝和深拷贝

在 Python 的上下文中（特别是拷贝机制），**“独立”**和**“完全独立”**通常用来区分**浅拷贝（Shallow Copy）**和**深拷贝（Deep Copy）**。

它们的核心区别在于：**能否彻底切断与原对象内部嵌套子对象的关联**。

为了让你一眼看明白，我们先看结论，再看代码图解：

### 1. 核心区别（结论）

|特性|独立（浅拷贝）|完全独立（深拷贝）|
|---|---|---|
|**操作方式**| `copy.copy()` 或 `a[:]` | `copy.deepcopy()` |
|**最外层容器**|**完全独立**（新建对象）|**完全独立**（新建对象）|
|**内部的子对象**（如嵌套的列表/字典）|**不独立**（**共享**同一个子对象）|**完全独立**（递归创建了全新的子对象）|
|**修改顶层元素**（如 `list[0] = x`）|互不影响 ✅|互不影响 ✅|
|**修改内层元素**（如 `list[0][0] = x`）|**互相影响** ❌|互不影响 ✅|

---

### 2. 案例剖析

看下面的例子，`a` 是一个嵌套列表（列表里面套列表）：

 import copy  
 ​  
 a = [[1, 2], [3, 4]]  
 ​  
 # b 是 独立（浅拷贝）——只拷贝了最外层  
 b = a[:]    
 ​  
 # c 是 完全独立（深拷贝）——递归拷贝了所有层  
 c = copy.deepcopy(a)  
 ​  
 # ---------- 实验：修改内层元素 ----------  
 a[0][0] = 99  
 ​  
 print(b)  # 输出: [[99, 2], [3, 4]]  <-- 被影响了！  
 print(c)  # 输出: [[1, 2], [3, 4]]   <-- 完好无损！

---

### 3. 内存图解

为了搞清楚为什么 `b` 会被影响，我们看看内存里的指向关系：

- **变量 `a` **：指向最外层的盒子。
    
- **变量 `b`（独立）**：`b = a[:]` 新建了一个**外层盒子**，但里面的两个小盒子（内层列表）**直接复制了地址**，和 `a` 共享。
    
- **变量 `c`（完全独立）**：`deepcopy` 连里面的两个小盒子也新建了。
    

 1. 原始对象 a  
 ┌─────────────────────┐  
 │     最外层列表 A      │  
 │  ┌──────┐ ┌──────┐  │  
 │  │内层 1 │ │内层 2 │  │  
 │  └──────┘ └──────┘  │  
 └─────────────────────┘  
 ​  
 2. 执行 b = a[:] 后（b 独立）  
 ┌───────────┐         ┌───────────┐  
 │ 外层列表 A │ ←── a   │ 外层列表 B │ ←── b  
 │ ┌──────┐  │         │ ┌──────┐  │  
 │ │内层 1 │◀─┼─────────┼─│内层 1 │◀─┼── 指向同一个内层对象！  
 │ └──────┘  │         │ └──────┘  │  
 │ ┌──────┐  │         │ ┌──────┐  │  
 │ │内层 2 │◀─┼─────────┼─│内层 2 │  │  
 │ └──────┘  │         │ └──────┘  │  
 └───────────┘         └───────────┘  
 ​  
 3. 执行 c = deepcopy(a) 后（c 完全独立）  
 ┌───────────┐         ┌───────────┐  
 │ 外层列表 A │         │ 外层列表 C │ ←── c  
 │ ┌──────┐  │         │ ┌──────┐  │  
 │ │内层 1 │  │         │ │内层 3 │  │ ← 全新的内层对象！  
 │ └──────┘  │         │ └──────┘  │  
 │ ┌──────┐  │         │ ┌──────┐  │  
 │ │内层 2 │  │         │ │内层 4 │  │  
 │ └──────┘  │         │ └──────┘  │  
 └───────────┘         └───────────┘

---

### 4. 什么时候必须用“完全独立”？

当你修改的对象**不是整个替换元素**（如 `b[0] = 100`），而是**修改元素内部的属性**（如 `b[0].append(100)` 或 `b[0][0] = 100`）时，就必须使用深拷贝（完全独立），否则原始数据会被污染。

### 5. 一句话总结

- **独立（浅拷贝）** = 你复印了一张纸条，但纸条上写着的**储物柜编号（引用）**和原来那张一模一样。你打开储物柜改东西，两张纸条都能看到变化。
    
- **完全独立（深拷贝）** = 你把储物柜里的东西**全部取出来，复印了一份**，放进了全新的柜子里。不管你怎么改新柜子，都不影响原来的旧柜子。

# 字符串池和小整数池

这是一个非常经典的 Python 面试知识点！**小整数池**和**字符串池（字符串驻留）**都是 Python 为了**性能优化**而做的缓存机制，但它们的实现方式和范围完全不同。

---

## 1. 小整数池（Small Integer Cache）

### 定义
Python 在启动时，会**预先创建**范围在 ** `[-5, 256]` ** 之间的整数对象，并缓存在内存中供所有程序共享。

### 特点
- **范围固定**：`-5, -4, ..., 0, 1, 2, ..., 255, 256`（共 262 个）
- **全局共享**：无论你在代码的哪里使用这些数字，它们都指向**同一个内存地址**
- **不可变**：整数是不可变对象，所以共享是安全的

### 示例
```python
a = 256
b = 256
print(a is b)  # True —— 指向同一个对象（小整数池）

c = 257
d = 257
print(c is d)  # False —— 不在池中，创建了两个不同对象

# 特殊情况：在交互式环境（REPL）中，257 也可能被复用（编译器优化），但不保证
```

### 内存图
```
小整数池（预分配）
┌─────┬─────┬─────┬─────┬─────┬─────┐
│ -5  │ -4  │ ... │ 255 │ 256 │     │  ← 固定的 262 个对象
└─────┴─────┴─────┴─────┴─────┴─────┘
  ↑      ↑            ↑      ↑
  │      │            │      │
  a      b            x      y     ← 所有变量都指向这些预分配对象
```

## 2. 字符串池（String Interning / 字符串驻留）

### 定义
Python 会**复用**某些字符串对象，让相同内容的字符串指向**同一内存地址**，以节省内存和提高比较速度。

### 触发条件（何时驻留）
字符串池的规则比整数池**复杂得多**，不是所有字符串都会被驻留：

| 情况 | 是否驻留 | 示例 |
|------|----------|------|
| **只包含字母、数字、下划线**（标识符风格） | ✅ 是 | `"hello"`, `"abc123"`, `"_test"` |
| **长度 > 1 且包含特殊字符**（空格、标点等） | ❌ 否 | `"hello world"`, `"abc!"` |
| **长度 = 1 的字符** | ✅ 是（所有字符都驻留） | `"a"`, `"9"`, `"@"` |
| **空字符串** | ✅ 是 | `""` |
| **在编译时确定的字符串常量** | ✅ 是 | `"hello" + "world"` 可能合并为一个常量 |
| **运行时动态生成的字符串**（`input()`, `str()` 等） | ❌ 否 | `str(123)` 通常不驻留 |

### 示例
```python
# 情况1：标识符风格 → 驻留
a = "hello"
b = "hello"
print(a is b)  # True

# 情况2：包含特殊字符 → 不驻留
c = "hello world"
d = "hello world"
print(c is d)  # False（在交互式环境中）

# 情况3：编译时合并 → 驻留
e = "hello" + "world"  # 编译时优化为 "helloworld"
f = "helloworld"
print(e is f)  # True

# 情况4：运行时生成 → 不驻留
g = "".join(["h", "e", "l", "l", "o"])
h = "hello"
print(g is h)  # False
```

---

## 3. 核心区别对比

| 特性 | 小整数池 | 字符串池（驻留） |
|------|----------|------------------|
| **缓存内容** | 整数（`-5` ~ `256`） | 部分字符串 |
| **触发机制** | **自动**，Python 启动时预创建 | **有条件自动**，由编译器或解释器决定 |
| **可手动控制** | ❌ 无法手动添加 | ✅ 可以使用 `sys.intern()` 手动驻留 |
| **范围** | 固定 262 个 | 不固定，由运行时决定 |
| **内存分配** | 程序启动时一次性分配 | 按需分配，缓存在一个全局字典中 |
| **设计目的** | 避免频繁创建小整数对象 | 节省内存，加速字符串比较和字典查找 |

---

## 4. `sys.intern()` —— 手动字符串驻留

Python 提供了 `sys.intern()` 方法，可以**强制**将字符串放入池中：

```python
import sys

a = "hello world"  # 通常不驻留
b = "hello world"

print(a is b)      # False

# 手动驻留
a_intern = sys.intern(a)
b_intern = sys.intern(b)

print(a_intern is b_intern)  # True —— 现在指向同一个对象
```

**使用场景**：
- 处理大量重复字符串（如解析 CSV、日志文件）
- 需要频繁比较字符串（`is` 比较比 `==` 快）
