# Module（模块）

- 语言级别的封装单位，通常对应一个源文件或一组源文件。
- 核心特征是**有明确的对外接口和隐藏的内部实现**（information hiding）。
- 例：Python 的 `.py` 文件、Java 的 `module-info.java`、Rust 的 `mod`。
- 关注点：**命名空间、可见性、依赖方向**

# Package（包）

- 比 module 更偏**分发与命名**的单位，语义在不同语言里不一致：
  - Java：`package` 是命名空间，`jar` 才是分发单位；
  - Python：`package` 是含 `__init__.py` 的目录；
  - npm/Go：`package` 既是命名空间也是分发单位。
- 关注点：**命名空间管理、可发布性**。

# Library（库）

- 可被其他代码**复用**的代码集合，强调"被依赖"的角色。
- 与 package 的区别：library 是**角色**，package 是**形态**。一个 library 可能由多个 package 组成。
- 关注点：**API 稳定性、版本兼容、复用价值**。
