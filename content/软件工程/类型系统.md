
# Primitive / Composite Type（原始类型 / 符合类型）

**原始类型（Primitive）**：语言内置、不可再分的基本类型。
- 例：`Int`、`Float`、`Bool`、`Char`、`String`（某些语言里 String 是复合的）

**复合类型（Composite）**：由其他类型组合而成的类型。
- 例：数组 `[Int]`、元组 `(Int, String)`、结构体 `struct Point { x: Int, y: Int }`

> 区别核心：是否由其他类型“构造”出来。

# Product Type (积类型)

**定义**：一个类型的值同时包含多个字段，字段数量是“笛卡尔积”关系。

- 例：`(A, B)`、`struct { a: A, b: B }`
- 可能的值数量 = `|A| × |B|`

**直观理解**：”A 和 B 同时都有“。


# Sum Type（和类型）

**定义**：一个类型的值只能是若干变体中的一种。

- 例：`A | B`、`enum { Left(A), Right(B) }`
- 可能的值数量 = `|A| + |B|`

**直观理解**：”A 或 B，二选一“。

# Algebraic Data Types（代数数据类型，ADT）

**定义**：由 Product 和 Sum 组合而成的类型系统。

- 名字来源：类型可以像代数一样运算（× 表示积，+ 表示和）
- 例（Haskell）：
```haskell
data Shape = Circle Float | Rectangle Float Float
```
  这是 Sum of Products。

**意义**：用少量原语构造出丰富的数据结构，且能保证穷尽性。

# Enum / Tagged Union（枚举 / 带标签联合）

**Enum**：一组命名的常量。
- 例：`enum Color { Red, Green, Blue }`

**Tagged Union**：每个变体带标签，且可携带数据。
- 例（Rust）：
  ```rust
  enum Message {
      Quit,
      Move { x: i32, y: i32 },
      Write(String),
  }
  ```
- 也叫： discriminated union、variant、sum type 的实现形式。

> Enum 是 Tagged Union 的简化版（无数据）。

# Pattern Matching（模式匹配）

**定义**：根据值的结构进行分支判断并解构。

- 例（Rust）：
  ```rust
  match msg {
      Message::Quit => ...,
      Message::Move { x, y } => ...,
      Message::Write(s) => ...,
  }
  ```
- 特点：编译器可检查是否穷尽所有情况（exhaustiveness check）

**意义**：与 Sum Type 搭配，安全地解构数据。
