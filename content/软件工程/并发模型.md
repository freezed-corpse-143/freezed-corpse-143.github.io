# 底层原语（OS / 硬件级）

这些是其他一切抽象的地基。

| 概念            | 作用            | 关键点                                             |
| ------------- | ------------- | ----------------------------------------------- |
| **Thread**    | 操作系统调度的最小执行单元 | 共享同一地址空间；切换开销大；数量受限于内存栈                         |
| **Mutex**     | 互斥锁，保护临界区     | 保证同一时刻只有一个线程进入；会阻塞；可能死锁                         |
| **Semaphore** | 计数信号量         | 控制"同时访问某资源的数量"；Mutex 是它的特例（=1）                  |
| **Atomic**    | 原子操作          | 无锁；CPU 指令级保证（CAS、fetch-add）；是 Lock-free 数据结构的基础 |

**核心问题**：这些原语直接组合极易出错（死锁、竞态、优先级反转）。于是有了更高层抽象。
