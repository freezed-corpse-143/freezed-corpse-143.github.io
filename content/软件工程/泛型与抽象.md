泛型：类型参数化，决定具体用什么类型，调用时才定。
多态：同一接口，多种实现，决定运行时 / 实现时才定。

# 多态的三种形态

- 参数化多态（Parametric Polymorphism）：对任意类型都一样的代码。
	- 语言机制：`Generics`（Java/C#/Rust）、`Templates`（C++）、类型变量（Haskell）
	- 例子：`List<T>`、`fn identity<T>(x: T) -> T`
- 子类型多态（Subtype Polymoriphism）："通过继承/实现接口，运行时替换实现"。
	- 语言机制：`Interface`（Java/Go）、虚函数、`Trait Object`（Rust）、`Protocol`（Swift）
	- 例子：`Animal a = new Dog(); a.speak();`
- 特设多态（Ad-hoc Polymorphism）："同一个名字，对不同类型有不同实现"。
	- 语言机制：**函数重载**、**Typeclass**（Haskell）、**Trait**（Rust 的静态分发侧）、运算符重载
	- 例子：`+` 对 int 和 string 行为不同；`Show a => a -> String`

> **Rust Trait / Go Interface / Haskell Typeclass / OO Interface** 之所以感觉像，是因为它们都在**同时**提供第 2 和第 3 种多态：
> - Trait 当泛型约束 → 特设（编译期单态化）
> - Trait 当 `dyn Trait` → 子类型（运行期动态分发）
> - Go Interface → 主要是子类型（隐式实现）
> - Typeclass → 特设，但可静态也可动态

# Generics (泛型)

**定义**：把类型作为参数，让一份代码适配多种类型。

```rust
// Rust
fn largest<T: PartialOrd>(list: &[T]) -> &T {
    let mut max = &list[0];
    for item in list {
        if item > max { max = item; }
    }
    max
}
```

```java
// Java
class Box<T> {
    private T value;
    void set(T v) { this.value = v; }
    T get() { return value; }
}
```

**本质**：类型层面的"函数参数"，编译期确定，零运行时开销（单态化）或有擦除开销（Java）。

# Polymorphism（多态）

**定义**：同一接口，不同实现。分三种：

```java
// 子类型多态
Animal a = new Dog();
a.speak();   // "Woof"

// 参数化多态（泛型）
List<String> xs = new ArrayList<>();

// 特设多态（重载）
void print(int x)    { }
void print(String s) { }
```

**本质**：一个名字/接口，背后可以是多种东西。是"抽象"的总称。
