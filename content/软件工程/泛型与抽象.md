泛型：类型参数化，决定具体用什么类型，调用时才定。
多态：同一接口，多种实现，决定运行时 / 实现时才定。

# 多态的三种形态

- 参数化多态（Parametric Polymorphism）：对任意类型都一样的代码。
	- 语言机制：`Generics`（Java/C#/Rust）、`Templates`（C++）、类型变量（Haskell）
	- 例子：`List<T>`、`fn identity<T>(x: T) -> T`
- 子类型多态（Subtype Polymoriphism）："通过继承/实现接口，运行时替换实现"。
	- 语言机制：`Interface`（Java/Go）、虚函数、`Trait Object`（Rust）、`Protocol`（Swift）
	- 例子：`Animal a = new Dog(); a.speak();`
- 特设多态（Ad-hoc Polymorphism）："同一个名字，对不同类型有不同实现"。
	- 语言机制：**函数重载**、**Typeclass**（Haskell）、**Trait**（Rust 的静态分发侧）、运算符重载
	- 例子：`+` 对 int 和 string 行为不同；`Show a => a -> String`

> **Rust Trait / Go Interface / Haskell Typeclass / OO Interface** 之所以感觉像，是因为它们都在**同时**提供第 2 和第 3 种多态：
> - Trait 当泛型约束 → 特设（编译期单态化）
> - Trait 当 `dyn Trait` → 子类型（运行期动态分发）
> - Go Interface → 主要是子类型（隐式实现）
> - Typeclass → 特设，但可静态也可动态

# Generics (泛型)

**定义**：把类型作为参数，让一份代码适配多种类型。

```rust
// Rust
fn largest<T: PartialOrd>(list: &[T]) -> &T {
    let mut max = &list[0];
    for item in list {
        if item > max { max = item; }
    }
    max
}
```

```java
// Java
class Box<T> {
    private T value;
    void set(T v) { this.value = v; }
    T get() { return value; }
}
```

**本质**：类型层面的"函数参数"，编译期确定，零运行时开销（单态化）或有擦除开销（Java）。

# Polymorphism（多态）

**定义**：同一接口，不同实现。分三种：

```java
// 子类型多态
Animal a = new Dog();
a.speak();   // "Woof"

// 参数化多态（泛型）
List<String> xs = new ArrayList<>();

// 特设多态（重载）
void print(int x)    { }
void print(String s) { }
```

**本质**：一个名字/接口，背后可以是多种东西。是"抽象"的总称。

# Interface（接口，OO 风格）

**定义**：显式声明一组方法，类去实现它。

```java
interface Shape {
    double area();
}

class Circle implements Shape {
    double r;
    public double area() { return Math.PI * r * r; }
}

class Square implements Shape {
    double s;
    public double area() { return s * s; }
}

// 使用
List<Shape> shapes = List.of(new Circle(), new Square());
shapes.forEach(s -> System.out.println(s.area()));
```

**本质**：显式的"能力契约"。**必须声明 implements**，运行时通过 vtable 动态分发。

# Trait (Rust 的接口 + 泛型约束)

**定义**：既像接口，又能当泛型约束，还能有默认实现。

```rust
trait Shape {
    fn area(&self) -> f64;

    // 默认实现
    fn describe(&self) -> String {
        format!("area = {:.2}", self.area())
    }
}

struct Circle { r: f64 }
impl Shape for Circle {
    fn area(&self) -> f64 { std::f64::consts::PI * self.r * self.r }
}

// 静态分发（单态化，零开销）
fn print_area<T: Shape>(s: &T) {
    println!("{}", s.describe());
}

// 动态分发（trait object）
fn print_dyn(s: &dyn Shape) {
    println!("{}", s.describe());
}
```

**本质**：Interface 的超集。可静态（`<T: Trait>`）可动态（`dyn Trait`），还能有默认方法、关联类型、运算符重载。

# Protocol（协议，Swift / Python 风格）

**定义**：和 Interface/Trait 同类，但更强调"鸭子类型"。

```swift
// Swift
protocol Greetable {
    func greet() -> String
}

struct English: Greetable {
    func greet() -> String { "Hello" }
}
struct Chinese: Greetable {
    func greet() -> String { "你好" }
}

func welcome(_ g: Greetable) {
    print(g.greet())
}
```

```python
# Python：协议是隐式的（鸭子类型）
class Dog:
    def speak(self): return "Woof"

class Robot:
    def speak(self): return "Beep"

for x in [Dog(), Robot()]:
    print(x.speak())   # 不需要声明接口
```

**本质**：契约的另一种叫法。Python 走"隐式协议"（只看有没有方法），Swift 走显式声明。

# Typeclass（Haskell 的特设多态）

**定义**：按类型分派的行为契约，可以事后给已有类型"补"实现。

```haskell
class Describable a where
    describe :: a -> String

data Circle = Circle Double
instance Describable Circle where
    describe (Circle r) = "circle area " ++ show (pi * r * r)

data Square = Square Double
instance Describable Square where
    describe (Square s) = "square area " ++ show (s * s)

-- 使用：多态函数
printAll :: Describable a => [a] -> IO ()
printAll = mapM_ (putStrLn . describe)
```

**本质**：Trait 的"更自由版"。**关键区别**：Typeclass 可以给**不是自己定义的类型**补实例（只要类型和类在同一个模块），Rust 的 trait 也支持，但 Java Interface 不行（必须改类）。

# Strategy Pattern（策略模式）

**定义**：把算法抽成对象，运行时替换。

```java
interface SortStrategy {
    void sort(int[] a);
}

class QuickSort implements SortStrategy {
    public void sort(int[] a) { /* ... */ }
}
class MergeSort implements SortStrategy {
    public void sort(int[] a) { /* ... */ }
}

class Sorter {
    private SortStrategy strategy;
    Sorter(SortStrategy s) { this.strategy = s; }
    void run(int[] a) { strategy.sort(a); }
}

// 使用
new Sorter(new QuickSort()).run(data);
new Sorter(new MergeSort()).run(data);
```

**本质**：**OO 时代没有一等函数时，用对象模拟"传函数"**。有了 HOF，它退化成：

```javascript
const sorter = (arr, cmp) => arr.sort(cmp);
sorter(data, (a,b) => a-b);
```

# Template Method（模板方法）

**定义**：父类定算法骨架，子类填具体步骤。

```java
abstract class DataProcessor {
    // 骨架：固定流程
    public final void process() {
        read();
        transform();
        write();
    }
    abstract void read();
    abstract void transform();
    abstract void write();
}

class CsvProcessor extends DataProcessor {
    void read()    { System.out.println("read csv"); }
    void transform(){ System.out.println("transform csv"); }
    void write()   { System.out.println("write csv"); }
}
```

**本质**：**继承版的 Strategy**。用"子类覆盖钩子"实现变化点。FP 里等价于"传一组函数进来"：

```javascript
const process = ({read, transform, write}) => {
    read(); transform(); write();
};
```


# Higher-order Function（高阶函数）

**定义**：接收函数作为参数，或返回函数的函数。

```javascript
// 接收函数
[1,2,3].map(x => x * 2);           // [2,4,6]
[1,2,3].filter(x => x > 1);        // [2,3]
[1,2,3].reduce((a,b) => a+b, 0);   // 6

// 返回函数
const adder = n => x => x + n;
const add5 = adder(5);
add5(3);  // 8
```

```haskell
-- Haskell 里 HOF 是家常便饭
map (*2) [1,2,3]        -- [2,4,6]
filter (>1) [1,2,3]     -- [2,3]
foldr (+) 0 [1,2,3]     -- 6
```

**本质**：**函数是一等公民**。Strategy / Template Method 的"轻量替代品"。

# Closure (闭包)

**定义**：能捕获外部变量的函数值。

```javascript
function counter() {
    let n = 0;
    return () => ++n;   // 捕获 n
}
const c = counter();
c(); // 1
c(); // 2
```

```rust
let n = 10;
let add_n = |x| x + n;   // 捕获 n
add_n(5);  // 15

// move 闭包：夺走所有权
let s = String::from("hi");
let f = move || println!("{}", s);
```

**本质**：**HOF 的载体**。没有闭包，HOF 只能传"顶层函数"，不能带上下文。有了闭包，才能"传一个带状态的策略"。

# Composition（组合）

**定义**：用小的部件拼出大的，优于继承。

```typescript
// 函数组合
const compose = <A,B,C>(f: (b:B)=>C, g: (a:A)=>B) => (a:A) => f(g(a));

const double = (x: number) => x * 2;
const inc    = (x: number) => x + 1;

const doubleThenInc = compose(inc, double);
doubleThenInc(3);  // (3*2)+1 = 7
```

```rust
// Rust：结构体组合
struct Engine;
struct Wheels;
struct Car {
    engine: Engine,
    wheels: Wheels,
}
// Car "has-a" Engine，而非 "is-a"
```

```go
// Go：接口组合
type Reader interface { Read() }
type Writer interface { Write() }
type ReadWriter interface {
    Reader
    Writer
}
```

**本质**：**"has-a / uses-a" 优于 "is-a"**。函数组合、对象组合、接口组合，都是同一思想。

# 5 种写法示例

**任务**：对一组形状求面积和。

```java
// Java：Interface + 子类型多态
interface Shape { double area(); }
double total(List<Shape> xs) {
    double s = 0;
    for (Shape x : xs) s += x.area();
    return s;
}
```

```rust
// Rust：Trait + 泛型（静态）
trait Shape { fn area(&self) -> f64; }
fn total<T: Shape>(xs: &[T]) -> f64 {
    xs.iter().map(|x| x.area()).sum()
}
```

```haskell
-- Haskell：Typeclass
class Shape a where area :: a -> Double
total :: Shape a => [a] -> Double
total = sum . map area
```

```go
// Go：隐式 Interface
type Shape interface { Area() float64 }
func total(xs []Shape) float64 {
    var s float64
    for _, x := range xs { s += x.Area() }
    return s
}
```

```javascript
// JS：HOF + Closure
const total = (xs, area) => xs.reduce((s, x) => s + area(x), 0);
total(shapes, s => Math.PI * s.r ** 2);
```

**看出规律了吗？**
- Java/Go：契约显式，动态分发
- Rust：契约显式，可静态可动态
- Haskell：契约显式，按类型分派
- JS：契约隐式（直接传函数），最灵活也最不安全
