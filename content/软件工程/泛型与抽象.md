泛型：类型参数化，决定具体用什么类型，调用时才定。
多态：同一接口，多种实现，决定运行时 / 实现时才定。

# 多态的三种形态

- 参数化多态（Parametric Polymorphism）：对任意类型都一样的代码。
	- 语言机制：`Generics`（Java/C#/Rust）、`Templates`（C++）、类型变量（Haskell）
	- 例子：`List<T>`、`fn identity<T>(x: T) -> T`
- 子类型多态（Subtype Polymoriphism）："通过继承/实现接口，运行时替换实现"。
	- 语言机制：`Interface`（Java/Go）、虚函数、`Trait Object`（Rust）、`Protocol`（Swift）
	- 例子：`Animal a = new Dog(); a.speak();`
- 特设多态（Ad-hoc Polymorphism）："同一个名字，对不同类型有不同实现"。
	- 语言机制：**函数重载**、**Typeclass**（Haskell）、**Trait**（Rust 的静态分发侧）、运算符重载
	- 例子：`+` 对 int 和 string 行为不同；`Show a => a -> String`

> **Rust Trait / Go Interface / Haskell Typeclass / OO Interface** 之所以感觉像，是因为它们都在**同时**提供第 2 和第 3 种多态：
> - Trait 当泛型约束 → 特设（编译期单态化）
> - Trait 当 `dyn Trait` → 子类型（运行期动态分发）
> - Go Interface → 主要是子类型（隐式实现）
> - Typeclass → 特设，但可静态也可动态

# Generics (泛型)

**定义**：把类型作为参数，让一份代码适配多种类型。

```rust
// Rust
fn largest<T: PartialOrd>(list: &[T]) -> &T {
    let mut max = &list[0];
    for item in list {
        if item > max { max = item; }
    }
    max
}
```

```java
// Java
class Box<T> {
    private T value;
    void set(T v) { this.value = v; }
    T get() { return value; }
}
```

**本质**：类型层面的"函数参数"，编译期确定，零运行时开销（单态化）或有擦除开销（Java）。

# Polymorphism（多态）

**定义**：同一接口，不同实现。分三种：

```java
// 子类型多态
Animal a = new Dog();
a.speak();   // "Woof"

// 参数化多态（泛型）
List<String> xs = new ArrayList<>();

// 特设多态（重载）
void print(int x)    { }
void print(String s) { }
```

**本质**：一个名字/接口，背后可以是多种东西。是"抽象"的总称。

# Interface（接口，OO 风格）

**定义**：显式声明一组方法，类去实现它。

```java
interface Shape {
    double area();
}

class Circle implements Shape {
    double r;
    public double area() { return Math.PI * r * r; }
}

class Square implements Shape {
    double s;
    public double area() { return s * s; }
}

// 使用
List<Shape> shapes = List.of(new Circle(), new Square());
shapes.forEach(s -> System.out.println(s.area()));
```

**本质**：显式的"能力契约"。**必须声明 implements**，运行时通过 vtable 动态分发。

# Trait (Rust 的接口 + 泛型约束)

**定义**：既像接口，又能当泛型约束，还能有默认实现。

```rust
trait Shape {
    fn area(&self) -> f64;

    // 默认实现
    fn describe(&self) -> String {
        format!("area = {:.2}", self.area())
    }
}

struct Circle { r: f64 }
impl Shape for Circle {
    fn area(&self) -> f64 { std::f64::consts::PI * self.r * self.r }
}

// 静态分发（单态化，零开销）
fn print_area<T: Shape>(s: &T) {
    println!("{}", s.describe());
}

// 动态分发（trait object）
fn print_dyn(s: &dyn Shape) {
    println!("{}", s.describe());
}
```

**本质**：Interface 的超集。可静态（`<T: Trait>`）可动态（`dyn Trait`），还能有默认方法、关联类型、运算符重载。

# Protocol（协议，Swift / Python 风格）

**定义**：和 Interface/Trait 同类，但更强调"鸭子类型"。

```swift
// Swift
protocol Greetable {
    func greet() -> String
}

struct English: Greetable {
    func greet() -> String { "Hello" }
}
struct Chinese: Greetable {
    func greet() -> String { "你好" }
}

func welcome(_ g: Greetable) {
    print(g.greet())
}
```

```python
# Python：协议是隐式的（鸭子类型）
class Dog:
    def speak(self): return "Woof"

class Robot:
    def speak(self): return "Beep"

for x in [Dog(), Robot()]:
    print(x.speak())   # 不需要声明接口
```

**本质**：契约的另一种叫法。Python 走"隐式协议"（只看有没有方法），Swift 走显式声明。
