# 泛型单态化

泛型单态化（Generic Monomorphization）是编程语言实现泛型的一种编译期策略：**编译器在编译时为每一组实际使用的具体类型参数，分别生成一份独立的、类型确定的代码副本**。

它主要出现在 Rust、C++（模板实例化）等语言中，与 Java 的“类型擦除”、Go 早期的“字典/装箱”等方案形成对比。

## 核心含义

以 Rust 为例：

```rust
fn identity<T>(x: T) -> T {
    x
}

fn main() {
    let a = identity(1i32);      // 生成 identity::<i32>
    let b = identity("hello");   // 生成 identity::<&str>
}
```

编译器看到 `identity` 被 `i32` 和 `&str` 各用了一次，就会生成两个具体函数，类似：

```rust
fn identity_i32(x: i32) -> i32 { x }
fn identity_str(x: &str) -> &str { x }
```

泛型参数 `T` 在生成的代码里已经被替换成具体类型，运行时不存在“泛型”这回事。

## 名称由来

“单态”（monomorphic）与“多态”（polymorphic）相对：

- **多态**：一份代码可以处理多种类型。
- **单态化**：把多态代码在编译期展开成多份只处理单一具体类型的代码。

所以泛型函数在源码层面是多态的，但编译产物里是多个单态函数。
