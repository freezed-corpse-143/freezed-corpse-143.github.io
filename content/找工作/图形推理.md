# 图形推理：常见套路、结构规律与解题顺序

图形推理不是只看“像不像”，而是先找对应关系，再找保持不变或按规则变化的特征。可以把一道题拆成三个问题：

1. **比较谁**：相邻图、隔项图、首尾图、九宫格同一行，还是不同组的对应位置？
2. **比较什么**：位置方向、点线面数量、对称性、元素种类、连接关系，还是空间结构？
3. **如何变化**：重复、递增、轮换、旋转、镜像、叠加、替换或组合？

备考资料通常按数量、位置、样式、属性等分类，并单列空间重构。[1][2] 本文在此基础上展开为可操作的检查清单，尤其区分**单幅图内部的几何关系**与**整组图之间的位置结构**。分类可以交叉，不是官方固定清单，也不代表考频排名；文中简例是教学示例，不冒充真题。

## 一、先认题型：不同题面，比较对象不同

| 题型 | 首先建立的对应关系 | 避免的误区 |
| --- | --- | --- |
| 单组序列 | 相邻项；不顺时再看隔项、周期、首尾 | 默认只能从左到右逐项递推 |
| 两组类比 | 第一组内部的关系，在第二组复用 | 要求两组图的外形或具体数量完全相同 |
| 九宫格 | 优先检查每行、每列能否使用同一规则 | 只解释一行，忽略另一完整行 |
| 分组分类 | 同类共享什么性质，不同类如何区分 | 把无序分类题硬当成有序数列 |
| 平面拼合 | 零件与目标的边、角、面积及缺口对应 | 未看题目限制就任意翻面、旋转 |
| 折叠、展开、立体视图 | 面、棱、顶点、观察方向的对应 | 仅凭图案相同就判定是同一立体 |

九宫格没有“必定横向”的定理。横纵关系解释不了，再考虑整体遍历、对角配对、中心与外围关系；蛇形或环形读法需要题面支持，不能任意重排来凑答案。

## 二、几何计数：把图形变成数列

### 1. 先确定到底数什么

| 计数对象 | 常见细分 | 识别与操作 |
| --- | --- | --- |
| 点 | 交点、端点、切点、标记点 | 交叉密集时分别统计；多个线条共点，几何位置只算一个交点 |
| 线 | 直线段、曲线、横线、竖线、斜线 | 先确定是否被交点分段、是否合并共线部分 |
| 角 | 直角、锐角、钝角、指定位置的角 | 不把所有射线配对形成的角与最小局部角混数 |
| 面 | 最小封闭区域、阴影区域、指定形状区域 | 内部划分明显时优先尝试；通常不把图外无限区域算入 |
| 特定子图 | 三角形、正方形、矩形等 | 注意是否包含由小图拼成的大图，以及倾斜图形 |
| 元素 | 总个数、种类数、各类个数 | “三个圆、两个三角形”是5个元素、2种形状 |
| 连通部分 | 互不连通的线条块或图形块 | 与原始图形个数不同；两个圆相交后线条整体可连通 |
| 对称要素 | 对称轴数量、旋转对称阶数 | 有无对称性是属性，轴有几条则可以转为计数 |
| 度量 | 阴影面积、长度、比例 | 优先用等分格、明确相等关系，不凭视觉估量细微差异 |

“点、线、角、面、素”不是让每题全部数一遍，而是根据显著特征选一两个候选量。[1][2]

### 2. 计数口径必须固定

**一个正方形画上两条对角线**：

- 最小封闭区域有4个；
- 由已画线段围成的三角形总数有8个，包括4个小三角形与4个大三角形；
- 若数线段，还必须说明按完整边线数，还是按交点切开的线段数。

因此，“数面”和“数三角形”不能互换。前者通常统计不再被线条细分的封闭区域，后者可能包含组合出来的大图。

又如，一条线段上依次标出A、B、C三点：最小相邻段是AB、BC，共2段；以标记点为端点的所有线段还包含AC，共3段。必须从题意及全部图形确定统一口径。

### 3. 数完之后，仍要找数值关系

- **恒定或分类**：每图都有3个交点；一类有奇数个区域，另一类有偶数个。
- **递增、递减、交替**：数量为1、2、3、4，或1、3、1、3。
- **行列运算**：每行前两图的面数之和等于第三图的面数。
- **分项统计**：黑点数递增，白点数递减，总数不变。
- **数量之间的关系**：每幅图中，内点数等于外框边数，或直线数比曲线数多1。

数量关系通常只给出必要条件；若多个选项数量相同，还要继续检查位置、属性等信息。

## 三、几何变换：元素没换，只是位置或姿态改变

| 变换 | 必须追踪的参数 | 典型套路 |
| --- | --- | --- |
| 平移 | 方向、步长、移动范围 | 每次向右一格；步长依次为1、2、3格 |
| 循环移动 | 固定路径与越界方式 | 沿四角循环，走到末端后回到起点 |
| 折返移动 | 边界与折返时机 | 到边缘后反向，而不是穿到另一边 |
| 旋转 | 中心、方向、角度 | 顺时针每次90°，或角度逐次增加 |
| 镜像反射 | 对称轴的位置与方向 | 关于竖直轴左右镜像，关于水平轴上下镜像 |
| 缩放 | 中心、倍率、是否等比例 | 图形由小到大，面积与边长变化不同 |
| 局部独立运动 | 各元素自己的轨迹 | 黑点顺时针走，白点逆时针走，外框不动 |
| 复合变换 | 操作次序 | 先旋转再移动，或先镜像再旋转 |

例如，一个有方向的箭头依次朝上、右、下、左，可用“每次顺时针旋转90°”解释；但箭头若还带一个偏心小点，必须同时验证小点的位置，不能只追踪箭头朝向。

### 旋转与镜像的区别

- 平移、旋转保持平面图形的定向；镜像会反转定向。可以追踪三个可区分、非共线标记的顺逆时针顺序。
- 对称图形可能在某次旋转和镜像后得到同一外观，此时不能仅凭轮廓断定具体操作。[2]
- “上下翻转”在平面题里常指关于水平轴的镜像，不等于在纸面内旋转180°。
- 平面镜像与把立体物体转个方向不是同一种操作。

### 先找不变量，再追运动

平移、旋转、镜像不改变长度、角度、面积及连接关系；等比例缩放保留角度和长度比例，但会改变长度与面积。因此，若图形的区域数确实变化，仅靠刚性移动不能解释。

多个相同元素可能难以逐个辨认。这时既要检查单个候选轨迹，也要检查整组元素的位置集合；不能每一步随意交换身份，只为凑出不同的步长。

## 四、样式运算：叠加、取同、去同、替换

元素组成相似而局部增减时，可考虑样式运算。[2]

### 1. 把图形看成对齐后的元素集合

| 运算 | 保留什么 | 注意事项 |
| --- | --- | --- |
| 并集叠加 | 任一图中存在的部分 | 重合部分只保留一份，不一定使数量相加 |
| 交集／去异存同 | 两图共有的部分 | “共有”通常要求位置对齐，而不只是形状相同 |
| 异或／去同存异 | 只在其中一图出现的部分 | 重合部分消失，非重合部分保留 |
| 有向相减 | 第一图有、第二图没有的部分 | A减B与B减A通常不同 |
| 补集／反色 | 固定范围内的有无或黑白互换 | 必须确定外框与操作范围 |
| 元素替换 | 按固定映射改变形状或填充 | 例如圆变三角形、三角形变正方形；映射须统一 |

**数量相加不等于图形叠加**：前两图分别有2个、3个元素，第三图有5个，可能只是计数关系；叠加还要求元素位置能逐项对应。

### 2. 黑白叠加：先反推规则，不默认异或

对同一格，记黑为1、白为0。以下是不同候选规则，不是可以混着使用的一套规则：

| A格 | B格 | 并集OR | 交集AND | 异或XOR | 同或XNOR |
| --- | --- | --- | --- | --- | --- |
| 白 | 白 | 白 | 白 | 白 | 黑 |
| 白 | 黑 | 黑 | 白 | 黑 | 白 |
| 黑 | 白 | 黑 | 白 | 黑 | 白 |
| 黑 | 黑 | 黑 | 黑 | 白 | 黑 |

做法：从完整的一行或一组中取相同位置，记录输入与输出；再用另一完整组验证。题干如果没出现某种输入组合，就不一定能唯一确定其输出，需要更多格子或选项约束。

若直接叠加失败，可以在有线索时尝试“先旋转或镜像，再叠加”，但同一预处理必须适用于其他组，不能只为缺项临时增加操作。

## 五、属性与相对关系：不一定要计算具体数量

### 1. 对称性

| 属性 | 判断标准 | 易错边界 |
| --- | --- | --- |
| 轴对称 | 关于某条直线反射后完全重合 | 轮廓对称但内部图案不对称，整体仍不对称 |
| 中心对称 | 绕某点旋转180°后完全重合 | 不是“只要能转某个角度重合”就算 |
| 旋转对称 | 旋转某个小于360°的非零角度后重合 | 正三角形可转120°重合，但不中心对称 |
| 对称轴变化 | 轴数、方向、轴与图案的位置关系变化 | 不能只看有轴或无轴 |

例如：非正方形的长方形有2条对称轴，正方形有4条；不带标记的圆有无穷多条，不能套用有限条数序列。正三角形有轴对称性，却没有中心对称性。[3]

对称判断要说明观察对象：整体、外框、内部线条还是阴影。若规律只作用于局部，需要题面支持，不能随意忽略其他部分。

### 2. 其他属性与关系

| 检查方向 | 可能规律 |
| --- | --- |
| 曲直性 | 全直线、全曲线、曲直混合；内外轮廓的曲直性交替 |
| 开闭性 | 是否形成闭合边界；开放线条与封闭区域的组合 |
| 凹凸性 | 凸图形与凹图形分类；凹口位置变化 |
| 填充属性 | 空心、实心、阴影、条纹方向依次轮换 |
| 包含关系 | 点在内部、边界上、外部；内外元素交换 |
| 接触关系 | 相离、点接触、边接触、交叉、包含 |
| 线条关系 | 平行、垂直、交叉；标记位于锐角区还是钝角区 |
| 交叠关系 | 交集的形状、区域数、位置变化 |
| 连通关系 | 外形不同，但分支、连接点、环的结构相同 |

“封闭区域有几个”“连通部分有几个”“独立元素有几个”是不同问题。例如两个互不相交的圆有两个连通部分；两个相交的圆，边界线整体连通，却产生多个封闭区域。

## 六、笔画与连接结构：一笔画不是凭手感描线

这里的一笔画指：**连续行走、不重复经过任何边，并走完所有边**；允许再次经过同一个顶点。它与汉字规范书写的笔画数不是同一个概念。[4]

将线图视为无向图：端点、分叉点、实际相连的交点是顶点，相邻顶点间的线条是边。顶点引出的边端数叫度数，度数为奇数的顶点叫奇点。

### 正确条件

对**连通且至少有一条边**的线图：

- 奇点数为0：可以一笔画，起终点相同。
- 奇点数为2：可以一笔画，起终点是这两个奇点。
- 奇点数大于2：不能一笔画。

若奇点数为 $o$，不重复边地画完该连通部分的最少笔数为：

$$\max(1,o/2)$$

若有多个互不连通、各自含边的部分，应分别计算再求和，不能只把全图奇点总数除以2。

### 几个检验例子

- 一个三角形：没有奇点，但需要1笔，不是0笔。
- 一个“十”字，交点连通：4个端点为奇点，中心度数为4，需要2笔。
- 两个互不相交的三角形：全图没有奇点，但需要2笔。
- 三条线在同一点贯穿相交：中心度数为6，仍是偶点，不是“3条线所以是奇点”。

如果交叉处明确画成跨线桥、断开或上下穿越，就不能擅自当成连通顶点。孤立实心点是否需要落笔，应按题意处理，不纳入上述含边分量公式。

部分备考资料把口诀简写成“笔画数＝奇点数÷2”；本文补足了连通性与零奇点的边界，不能照搬简写。[4]

## 七、整组图的位置结构：重复、对称、分块与遍历

这一层与数列推理相通。**单幅图轴对称**与**整组图按镜像位置对应**不是一回事。

| 结构套路 | 如何使用 |
| --- | --- |
| 奇偶项分流 | 第1、3、5幅一条规律，第2、4、6幅另一条规律 |
| 固定周期 | 形状、方向、颜色或操作按周期重复 |
| 首尾配对 | 第1与最后一幅、第2与倒数第2幅分别镜像、互补或同数量 |
| 分块复用 | 各块都执行相同操作，例如先旋转，再反色 |
| 块间同位映射 | 下一组第1幅对应上一组第1幅，而非只看整串相邻图 |
| 正倒序切换 | 第二组是第一组顺序倒转，或倒序后再统一变换 |
| 循环移位 | 每一行的元素顺序相对上一行左移或右移 |
| 遍历补缺 | 每行或每列均包含规定元素、方向或颜色，缺什么补什么 |
| 中心与外围 | 中心图由外围图生成，或外围围绕中心按固定规则变化 |
| 行列双重约束 | 行控制形状、列控制填充；缺项同时满足两者 |

### 1. 遍历不一定是运动

例如三行的形状依次为：

- 第一行：圆、三角形、正方形；
- 第二行：三角形、正方形、圆；
- 第三行：正方形、圆、待填。

若每行每列都要包含这三种形状，待填处应为三角形。这里既可以描述成行间循环移位，也可以描述成行列遍历；不必执着于唯一分类。

### 2. 遍历看“集合”，也可能要看“次数”

“每行都有圆和三角形”与“每行恰好有两个圆、一个三角形”不是同一规则。涉及重复元素时，要记录每类出现次数，不能只检查是否出现。

### 3. 多种特征可以各走各的规律

外形按“圆、三角形、正方形”循环，填充按“空心、实心”交替：两个属性的周期分别是3和2，组合状态每6项重复一次。

遇到复杂图，分别列出形状、填充、朝向、位置四条序列，通常比把整体当成一个不可拆的图案更清楚。但不要加入题面没有证据支持的新特征。

## 八、平面拼合与折纸剪孔

### 1. 平面拼合

先读操作限制：只能平移，还是允许旋转？是否允许翻面？是否可以重新切割？不要把默认的刚性拼合变成任意变形。

常用检查顺序：

1. **面积或单位格数守恒**：不重叠、不留缝的拼合，总面积相同。
2. **特殊边、角、缺口匹配**：长斜边、凹口、锐角优先。
3. **方向与手性**：镜像零件未必能靠平面旋转得到。
4. **整体覆盖**：最后检查所有零件都用到，没有重叠或空洞。

面积相同只是必要条件；周长通常不守恒，因为拼接后部分边会变成内部公共边。

### 2. 折纸与打孔、剪切

按**折叠的逆序**逐层展开，每展开一步，就把当前孔或切口关于该次折痕作相应镜像，并检查实际纸张覆盖范围。

- 远离折痕、且穿透全部重叠层的普通孔，展开后往往成对复制。
- 孔位于折痕上时，镜像可能重合，不能机械地每折一次就乘2。
- 非圆孔还要追踪方向，不能只数孔数。
- 孔靠近纸边、剪口穿过折痕或只穿透部分纸层时，要按具体轮廓判断。

例如正方形纸沿两条互相垂直的中线对折，在折后纸片内部远离折痕处打一个贯穿全部四层的小圆孔，展开后得到4个关于两条中线对称的孔。

## 九、空间推理：展开、视图、截面与立体拼合

### 1. 正方体展开与重构

先确定题目是正方体，不能把“六面体”这个泛称下的所有物体都套用正方体口诀。

- **相对面排除**：正方体相对面不共棱，不能组成同一个顶点处的三面组合。
- **相邻面不够**：面选对了，图案朝向仍可能错。
- **公共棱法**：固定两面的公共棱，追踪箭头、斜线、角标在棱的哪一侧。
- **公共顶点法**：确定三面相交的同一个顶点，比较图案与该顶点、相关棱的位置。[5]
- **整体旋转一致性**：一个选项必须能由同一次刚体旋转得到，不能把各面独立转到“看着对”。

展开图上不相邻的两面，折起后也可能相邻。因此，“纸上隔得远”不能直接当成“空间里相对”。

### 2. 三视图与遮挡

主视、俯视、侧视是从指定方向作正投影，不是随意透视画法。[6]

- 先固定前后、左右、上下方向，再判断轮廓。
- 区分实际存在的棱、被遮挡的棱、仅由零件划分造成但外表不存在的线。
- 虚线是否表示隐藏棱，按题目给定的画法判断。
- 正视与俯视对应宽度，正视与侧视对应高度，俯视与侧视对应深度；注意左右视方向不同。
- 多个立体可能具有相同的某一个视图，甚至同一组三视图也未必唯一确定内部结构，不能补造隐藏部分。

### 3. 截面：同一个平面与实体相交

“一刀切”意味着同一个平面，不能绕过障碍或中途拐弯。截面不是切开后看见的全部投影，也不是将几个位置的截面随意拼起来。[6]

- 对凸多面体，平面截面仍是凸的；若选项出现凹口，需要原物体有相应非凸或挖空结构。
- 正方体的非退化平面截面可以是三角形、四边形、五边形或六边形，不止矩形、梯形和三角形。
- 正方体有6个面，一个平面与每个面至多形成一条截面边，所以非退化截面至多6条边。
- 圆柱垂直轴线切可得圆，过轴线切可得矩形；斜切若不被上下底面截断，可得完整椭圆。不能把有限圆柱的一切斜截面都认作完整椭圆。
- 挖空或组合实体要同时求外轮廓与内部空缺，不能只认外形。

资料中的“常见截面”通常只是举例，不是完整枚举；也不要把正方体的结论推广到任意六面体。

### 4. 立体拼合与小方块计数

先用体积或单位立方体数排除，再检查凹凸、长短、连接方式及空间朝向。[1][6]

- **计数**：区分看得见的小方块与被遮住的部分；是否实心、是否逐层有支撑，要看题设。
- **匹配**：凸起能否进入凹口，位置、尺寸、方向是否都一致。
- **守恒**：零件总数或总体积相同，不代表一定能拼合。
- **整体验证**：局部缺口匹配之后，仍需检查其他部分是否碰撞、重叠或留空。

## 十、拿到题的实用检查顺序

没有适用于所有题目的唯一固定顺序。下面是按题面特征分流的建议，而不是“每题先数完所有点线面”。

1. **读要求**：选能成立还是不能成立？有无旋转、翻面、拼合限制？
2. **认结构**：序列、两组、九宫格、分类，还是空间题？确定比较对象。
3. **看变化最大的特征**：
   - 元素基本相同、方向位置变：先看平移、旋转、镜像；
   - 外框一致、局部线条增减：先看叠加、取同去同、替换；
   - 图形不同但很规整：先看对称、曲直、开闭等属性；
   - 交叉、分割或重复小元素突出：选择相应计数；
   - 分支线条明显：检查连通性与奇点；
   - 出现展开图、立体或折纸过程：转入对应空间规则。
4. **整体不顺就拆层**：分离外框与内部、黑与白、大与小、不同运动元素。
5. **提出最简单候选规则**：用所有完整行、列或组验证，不只解释最近两图。
6. **查看选项差异**：若只差方向，就重点追方向；若只差一个点的位置，就追该点的关系。
7. **最后检查剩余细节**：一个规则筛出多个选项时，不要宣布结束；继续检查题面支持的其他约束。

## 十一、最容易误用的口诀

- **“组成相同看位置”是优先方向，不是定理**：同样元素也可能考数量分配、接触关系或对称性。
- **“图形不同就数数”不可靠**：外形不同仍可能共享拓扑结构、轴对称性或包含关系。
- **“所有图都轴对称”可能只解释了一半**：还要检查轴数、轴角度、轴与标记的位置。
- **“黑白叠加就是异或”不可靠**：必须从完整组反推规则。
- **“奇点总数除以2”有边界**：要先检查连通部分，零奇点的闭环仍需要一笔。
- **“面积、体积相同就能拼上”不成立**：还要满足形状、朝向及不重叠约束。
- **“正方体相邻面都对就行”不成立**：面内图案朝向和三面组合的定向也要一致。
- **“找到某个规律就结束”不可靠**：必须解释全部适用图形，并能区分选项。

学习时建议把错题记录为“比较对象—观察特征—变换规则—漏掉的边界”，而不只记“这题选C”。
